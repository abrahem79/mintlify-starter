Google 平台汇集了广泛的基于云的服务，涵盖你查找、创建和分享信息的完整生命周期。无论你是在网络上搜索答案、与队友在共享文档中协作，还是在构建利用 Google 基础设施的应用程序，每一项服务都被设计为无缝协作——为个人、团队和开发者提供一个一致的基础来构建。

## Google 平台的三大支柱

Google 将其核心产品围绕三个相互连接的领域组织，每个领域都服务于不同但互补的目的。

### 1. Search

Google Search 是每天数十亿次查询的入口。除了网络搜索，Google 的搜索技术还为内部工具、嵌入你自己产品中的自定义搜索引擎，以及让你以编程方式获取和排序信息的 API 提供支持。理解 Search 的工作方式可以帮助你在正确的时间呈现正确的内容——无论是为你的用户还是为你自己。

### 2. Google Workspace

Google Workspace 是 Google 的基于云的生产力和协作应用套件。它包括 Gmail、Google Drive、Docs、Sheets、Slides 和 Meet，所有产品都围绕实时协作构建，可从任何设备访问。Workspace 的设计使你的整个团队都在同一个共享环境中工作，并对谁可以查看、评论或编辑你的内容进行细粒度控制。

### 3. 开发者 API

Google 提供了丰富的 API 集合，让你以编程方式访问其服务——从在应用程序中嵌入搜索结果，到读取和写入 Workspace 文档，再到集成身份验证、地图和机器学习模型。这些 API 遵循标准的 REST 和 gRPC 约定，使用 OAuth 2.0 进行授权，并在本文档的 API 参考部分完整记录。
