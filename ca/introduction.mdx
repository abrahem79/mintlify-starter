## Com funciona

Començar amb Google només et pren uns minuts. Segueix aquests tres passos per passar de zero a una integració completa.

<Steps>
  <Step title="Crea un compte de Google">
    Visita [accounts.google.com](https://accounts.google.com) i registra't per obtenir un compte de Google gratuït. El teu compte és el passaport a tots els serveis de Google: Search, Gmail, Drive, Cloud i més.
  </Step>
  <Step title="Activa els serveis que necessites">
    Vés a la [Google Cloud Console](https://console.cloud.google.com) per crear un projecte i activar les API i els serveis concrets que requereix el teu cas d'ús, com ara la Custom Search API, la Maps API o la Gmail API.
  </Step>
  <Step title="Connecta les teves aplicacions via l'API">
    Genera credencials d'API a la Cloud Console i utilitza les API REST o les biblioteques client de Google per integrar els serveis de Google directament a la teva aplicació. Consulta l'[Inici ràpid](/quickstart) per fer la teva primera crida a l'API en pocs minuts.
  </Step>
</Steps>
