## 작동 방식

Google을 시작하는 데는 몇 분이면 충분합니다. 다음 세 단계를 따라 완전히 통합된 상태까지 진행하세요.

<Steps>
  <Step title="Google 계정 만들기">
    [accounts.google.com](https://accounts.google.com)을 방문하여 무료 Google 계정에 가입하세요. 여러분의 계정은 Search, Gmail, Drive, Cloud 등 모든 Google 서비스로 통하는 여권입니다.
  </Step>
  <Step title="필요한 서비스 활성화하기">
    [Google Cloud Console](https://console.cloud.google.com)로 이동하여 프로젝트를 만들고, Custom Search API, Maps API, Gmail API 등 사용 사례에 필요한 특정 API와 서비스를 활성화하세요.
  </Step>
  <Step title="API로 앱 연결하기">
    Cloud Console에서 API 자격 증명을 생성하고 Google의 REST 또는 클라이언트 라이브러리 API를 사용하여 Google 서비스를 애플리케이션에 직접 통합하세요. 몇 분 안에 첫 API 호출을 만들려면 [Quickstart](/quickstart)를 확인하세요.
  </Step>
</Steps>
