Google のプラットフォームは、情報を見つけ、作成し、共有する一連のライフサイクル全体を網羅する幅広いクラウドサービスを 1 つに統合しています。答えを求めて Web を検索する場合でも、共有ドキュメントでチームメイトと共同作業する場合でも、Google のインフラを活用するアプリケーションを構築する場合でも、すべてのサービスはシームレスに連携するよう設計されており、個人、チーム、開発者に一貫した土台を提供します。

## Google プラットフォームの 3 つの柱

Google はコアとなる提供内容を、相互に補完しあう 3 つの領域に整理しています。それぞれが独立した、しかし補完的な目的を持ちます。

### 1. 検索

Google 検索は、毎日何十億ものクエリの入り口となっています。Web 検索にとどまらず、Google の検索技術は社内ツール、独自製品に組み込まれるカスタム検索エンジン、情報をプログラムから取得・ランキングできる API を支えています。検索の仕組みを理解することで、ユーザーや自分自身に対して、適切なコンテンツを適切なタイミングで表示できるようになります。

### 2. Google Workspace

Google Workspace は Google のクラウドベースの生産性・コラボレーションアプリケーション群です。Gmail、Google ドライブ、ドキュメント、スプレッドシート、スライド、Meet を含み、いずれもリアルタイム共同作業を中心に構築されており、あらゆるデバイスからアクセスできます。Workspace は、チーム全体が単一の共有環境で作業し、コンテンツを閲覧・コメント・編集できる相手をきめ細かく制御できるよう設計されています。

### 3. 開発者向け API

Google は、検索結果のアプリへの埋め込みから、Workspace ドキュメントの読み書き、認証・マップ・機械学習モデルの統合まで、サービスにプログラムからアクセスできる豊富な API を公開しています。これらの API は標準的な REST および gRPC の規約に従い、認可には OAuth 2.0 を使用し、詳細はこのドキュメントの API リファレンスセクションに記載されています。
