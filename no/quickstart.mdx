Beskriv hvordan noen begynner å bruke produktet ditt. Hva er det første de må gjøre? Finnes det noen forutsetninger?

En hurtigstart bør ta noen fra null til å bruke produktet ditt. De vil få en rask seier og en følelse av hva de kan oppnå.

## Forutsetninger

Før du begynner, må du ha:

- Krav én (for eksempel Node.js 18+, en gratis konto, en API-nøkkel)
- Krav to (for eksempel en kompatibel enhet, en kompatibel nettleser, et kompatibelt operativsystem)

## Kom i gang

<Steps>
  <Step title="Installer">
    Beskriv hvordan du installerer produktet ditt eller registrerer deg.

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="Konfigurer">
    Beskriv eventuelle oppsett eller konfigurasjoner som trengs før første gangs bruk.

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="Kjør det">
    Vis det første en bruker gjør for å se at det fungerer.

    ```bash
    your-cli start
    ```
  </Step>
</Steps>
