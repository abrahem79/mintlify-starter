title: "Inici ràpid"
description: "Comenceu amb una guia sobre el camí més ràpid cap a un resultat satisfactori"
---

Descriviu com algú comença a utilitzar el vostre producte. Quina és la primera cosa que ha de fer? Hi ha algun requisit previ?

Un inici ràpid ha de portar algú de zero a fer servir el vostre producte. Obtindrà una victòria ràpida i una idea del que pot aconseguir.

## Requisits previs

Abans de començar, heu de tenir:

- Requisit u (per exemple, Node.js 18+, un compte gratuït, una clau d'API)
- Requisit dos (per exemple, un dispositiu compatible, un navegador compatible, un sistema operatiu compatible)

## Comenceu

<Steps>
  <Step title="Instal·lació">
    Descriviu com instal·lar el vostre producte o registrar-se.

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="Configuració">
    Descriviu qualsevol preparació o configuració necessària abans del primer ús.

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="Executeu-lo">
    Mostreu la primera cosa que fa una persona usuària per veure'l funcionar.

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  Oferiu a les persones una manera d'obtenir ajuda. Podria ser un enllaç a una pàgina d'assistència, una conversa amb un agent d'atenció al client o un fòrum del vostre producte.

  Exemple: Necessiteu ajuda? Contacteu amb nosaltres a [support@yourcompany.com](mailto:support@yourcompany.com).
</Tip>
