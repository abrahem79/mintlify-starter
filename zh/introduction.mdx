## 工作原理

上手使用 Google 只需几分钟。按照以下三步，从零完成全面集成。

<Steps>
  <Step title="创建 Google 账户">
    访问 [accounts.google.com](https://accounts.google.com) 并免费注册一个 Google 账户。你的账户是通向每一项 Google 服务的通行证——搜索、Gmail、Drive、Cloud 等。
  </Step>
  <Step title="启用你需要的服务">
    前往 [Google Cloud Console](https://console.cloud.google.com) 创建一个项目，并启用你的用例所需的特定 API 和服务，例如 Custom Search API、Maps API 或 Gmail API。
  </Step>
  <Step title="通过 API 连接你的应用">
    在 Cloud Console 中生成 API 凭据，并使用 Google 的 REST 或客户端库 API 将 Google 服务直接集成到你的应用中。查看[快速开始](/quickstart)，在几分钟内完成你的第一个 API 调用。
  </Step>
</Steps>
