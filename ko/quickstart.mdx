---

사용자가 제품을 어떻게 사용하기 시작하는지 설명해 주세요. 가장 먼저 해야 할 일은 무엇인가요? 사전 요구 사항이 있나요?

빠른 시작은 사용자를 0에서 제품을 사용하는 단계까지 안내해야 합니다. 사용자는 빠른 성과를 얻고 무엇을 이룰 수 있는지 감을 잡을 수 있습니다.

## 사전 요구 사항

시작하기 전에 다음이 준비되어 있어야 합니다:

- 요구 사항 1 (예: Node.js 18+, 무료 계정, API 키)
- 요구 사항 2 (예: 호환 기기, 호환 브라우저, 호환 운영체제)

## 시작하기

<Steps>
  <Step title="설치">
    제품을 설치하거나 가입하는 방법을 설명하세요.

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="구성">
    처음 사용하기 전에 필요한 설정이나 구성 방법을 설명하세요.

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="실행하기">
    사용자가 동작을 확인하기 위해 가장 먼저 수행하는 작업을 보여주세요.

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  사용자가 도움을 받을 수 있는 방법을 제공하세요. 지원 페이지 링크, 고객 지원 담당자와의 채팅, 또는 제품 포럼 등이 될 수 있습니다.

  예시: 도움이 필요하신가요? [support@yourcompany.com](mailto:support@yourcompany.com)으로 문의해 주세요.
</Tip>
