이 quickstart는 Google 로그인, API 자격 증명 획득, 첫 API 요청 만들기까지 — 모두 10분 이내에 — 안내합니다. 완료하면 실시간 검색 결과를 반환하는 API 호출이 작동하게 되며, 이를 여러분의 애플리케이션에서 확장할 수 있습니다.

## 사전 요구사항

시작하기 전에 다음 사항을 확인하세요:

- **Google 계정** — 아직 없다면 [무료로 만드세요](https://accounts.google.com/signup).
- **기본적인 HTTP 지식** — GET/POST 요청을 보내고 JSON 응답을 읽는 데 익숙해야 합니다.
- 명령줄 터미널 또는 [curl](https://curl.se/), [Postman](https://www.postman.com/) 같은 HTTP 클라이언트.

## 단계

<Steps>
  <Step title="로그인">
    [accounts.google.com](https://accounts.google.com)으로 이동하여 Google 계정으로 로그인하세요. 처음이라면 진행하기 전에 계정 생성 흐름을 완료하세요.
  </Step>
  <Step title="API 자격 증명 얻기">
    1. [Google Cloud Console](https://console.cloud.google.com)을 여세요.
    2. 새 프로젝트를 만들거나 기존 프로젝트를 선택하세요.
    3. **APIs & Services → Library**로 이동하여 **Custom Search API**를 활성화하세요.
    4. **APIs & Services → Credentials**로 이동하여 **Create Credentials → API key**를 클릭하세요.
    5. 새 API 키를 복사하여 안전한 곳에 보관하세요.
    6. [programmablesearchengine.google.com](https://programmablesearchengine.google.com)에서 Programmable Search Engine을 만들고 **Search Engine ID**(`cx`)를 복사하세요.
  </Step>
  <Step title="첫 요청 만들기">
    아래 명령의 `YOUR_API_KEY`와 `YOUR_SEARCH_ENGINE_ID`를 복사한 값으로 바꾼 후 터미널에서 실행하세요:

    ```bash
    curl -X GET "https://www.googleapis.com/customsearch/v1?q=hello+world&key=YOUR_API_KEY&cx=YOUR_SEARCH_ENGINE_ID"
    ```
  </Step>
  <Step title="응답 확인하기">
    요청이 성공하면 검색 메타데이터와 결과 배열이 포함된 JSON 객체가 반환됩니다. 다음과 비슷한 응답을 볼 수 있어야 합니다:

    ```json
    {
      "kind": "customsearch#search",
      "url": {
        "type": "application/json",
        "template": "https://www.googleapis.com/customsearch/v1?q={searchTerms}&..."
      },
      "queries": {
        "request": [
          {
            "title": "Google Custom Search - hello world",
            "totalResults": "4970000000",
            "searchTerms": "hello world",
            "count": 10,
            "startIndex": 1
          }
        ]
      },
      "items": [
        {
          "kind": "customsearch#result",
          "title": "Hello, World! – Wikipedia",
          "htmlTitle": "\u003cb\u003eHello, World!\u003c/b\u003e – Wikipedia",
          "link": "https://en.wikipedia.org/wiki/%22Hello,_World!%22_program",
          "snippet": "A \"Hello, World!\" program is generally a simple computer program that outputs the phrase \"Hello, World!\" to a display device."
        }
      ]
    }
    ```

    `items` 배열에는 검색 결과가 담겨 있습니다. 각 객체에는 페이지 제목, URL(`link`), 그리고 UI에 바로 표시할 수 있는 짧은 `snippet`이 포함되어 있습니다.
  </Step>
</Steps>

<Tip>
  위의 예제는 인증을 위해 간단한 API 키를 사용합니다. Google API는 사용자 데이터에 접근하는 요청을 위해 OAuth 2.0도 지원합니다. 지원되는 모든 인증 방식에 대한 전체 설명은 [Authentication 가이드](/api/authentication)를 참조하세요.
</Tip>
