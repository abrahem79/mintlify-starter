Google 平台汇集了一整套基于云的服务，覆盖你查找、创建和分享信息的完整生命周期。无论你是在网上搜索答案、与队友在共享文档上协作，还是在构建一个使用 Google 基础设施的应用，每项服务都设计得能够无缝协同——为个人、团队和开发者提供一致的构建基础。

## Google 平台的三大支柱

Google 围绕三个相互关联的领域组织其核心业务，每个领域都有各自明确却互为补充的用途。

### 1. 搜索

Google 搜索是每天数十亿次查询的入口。除网页搜索外，Google 的搜索技术还支持内部工具、嵌入你自有产品中的自定义搜索引擎，以及让你以编程方式检索和排序信息的 API。理解搜索的运作方式有助于你在正确的时间呈现正确的内容——无论是为你的用户还是你自己。

### 2. Google Workspace

Google Workspace 是 Google 的一整套基于云的生产力和协作应用。它包括 Gmail、Google Drive、Docs、Sheets、Slides 和 Meet，全都围绕实时协作构建，可在任何设备上访问。Workspace 的设计让整个团队在单一共享环境中工作，同时提供对查看、评论或编辑内容者的精细控制。

### 3. 开发者 API

Google 提供了一整套丰富的 API，让你能以编程方式访问其服务——从将搜索结果嵌入你的应用，到读写 Workspace 文档，再到集成身份验证、地图和机器学习模型。这些 API 遵循标准的 REST 和 gRPC 约定，使用 OAuth 2.0 进行授权，并在本文档的 API 参考部分中有完整说明。
