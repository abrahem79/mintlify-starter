Google は、検索や Gmail から Google ドライブ、Google Cloud、豊富な開発者向け API まで、包括的なクラウドベースのサービス群を提供しています。これらは、個人、チーム、組織がより早く情報を見つけ、シームレスに共同作業し、あらゆる規模で強力なアプリケーションを構築できるように設計されています。Google API を製品に組み込む開発者の方も、初めてアカウントを設定する新規ユーザーの方も、このドキュメントがすべてのステップを丁寧にご案内します。

## 仕組み

Google を使い始めるのに必要な時間はほんの数分です。次の 3 つのステップで、ゼロから完全な統合までを実現できます。

<Steps>
  <Step title="Google アカウントを作成する">
    [accounts.google.com](https://accounts.google.com) にアクセスし、無料の Google アカウントを作成しましょう。アカウントは、検索、Gmail、ドライブ、Cloud など、あらゆる Google サービスへのパスポートです。
  </Step>
  <Step title="必要なサービスを有効化する">
    [Google Cloud Console](https://console.cloud.google.com) にアクセスしてプロジェクトを作成し、Custom Search API、Maps API、Gmail API など、ユースケースに応じて必要な API とサービスを有効化します。
  </Step>
  <Step title="API 経由でアプリを接続する">
    Cloud Console で API 認証情報を生成し、Google の REST またはクライアントライブラリの API を使って、Google サービスをアプリケーションに直接統合します。数分で最初の API 呼び出しを実行するには、[クイックスタート](/quickstart)をご覧ください。
  </Step>
</Steps>
