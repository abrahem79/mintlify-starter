Seja você um desenvolvedor integrando as APIs do Google ao seu produto ou um novo usuário configurando sua primeira conta, esta documentação vai guiar você em cada passo.

## Como Funciona

Começar a usar o Google leva apenas alguns minutos. Siga estes três passos para sair do zero até uma integração completa.

<Steps>
  <Step title="Crie uma Conta do Google">
    Acesse [accounts.google.com](https://accounts.google.com) e cadastre-se gratuitamente para obter uma Conta do Google. Sua conta é o passaporte para todos os serviços do Google — Pesquisa, Gmail, Drive, Cloud e muito mais.
  </Step>
  <Step title="Habilite os Serviços que Você Precisa">
    Acesse o [Console do Google Cloud](https://console.cloud.google.com) para criar um projeto e habilitar as APIs e serviços específicos que seu caso de uso requer, como a API do Custom Search, a API do Maps ou a API do Gmail.
  </Step>
  <Step title="Conecte seus Apps via API">
    Gere credenciais de API no Cloud Console e use as APIs REST ou as bibliotecas de cliente do Google para integrar os serviços do Google diretamente à sua aplicação. Confira o [Quickstart](/quickstart) para fazer sua primeira chamada de API em minutos.
  </Step>
</Steps>
