Google は、Search や Gmail から Google Drive、Google Cloud、そして充実した開発者向け API まで、包括的なクラウドサービス群を提供しています。個人・チーム・組織が情報をより速く見つけ、シームレスに協業し、あらゆる規模で強力なアプリケーションを構築できるよう設計されています。あなたが自社製品に Google API を統合する開発者であっても、初めてアカウントを作成する新規ユーザーであっても、このドキュメントがすべての手順をガイドします。

## 仕組み

Google を使い始めるのに必要なのは数分だけです。次の 3 つのステップに従って、ゼロから完全に統合された状態まで進みましょう。

<Steps>
  <Step title="Google アカウントを作成する">
    [accounts.google.com](https://accounts.google.com) にアクセスして、無料の Google アカウントを作成します。このアカウントは、Search、Gmail、Drive、Cloud などあらゆる Google サービスへのパスポートになります。
  </Step>
  <Step title="必要なサービスを有効化する">
    [Google Cloud Console](https://console.cloud.google.com) に移動してプロジェクトを作成し、Custom Search API、Maps API、Gmail API など、ユースケースに必要な API とサービスを個別に有効化します。
  </Step>
  <Step title="API 経由でアプリを接続する">
    Cloud Console で API 認証情報を生成し、Google の REST またはクライアントライブラリの API を使って Google サービスをアプリケーションに直接統合します。[クイックスタート](/quickstart) を参照して、数分で初めての API 呼び出しを行いましょう。
  </Step>
</Steps>
