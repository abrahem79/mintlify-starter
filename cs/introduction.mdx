## Jak to funguje

Začít používat Google trvá jen několik minut. Následujte tyto tři kroky, abyste přešli od nuly k plné integraci.

<Steps>
  <Step title="Vytvořte si účet Google">
    Přejděte na [accounts.google.com](https://accounts.google.com) a bezplatně si zaregistrujte účet Google. Váš účet je vstupenkou do každé služby Google — Vyhledávání, Gmailu, Disku, Cloudu a dalších.
  </Step>
  <Step title="Aktivujte služby, které potřebujete">
    Přejděte do [Google Cloud Console](https://console.cloud.google.com), vytvořte projekt a aktivujte konkrétní API a služby, které váš případ použití vyžaduje, například Custom Search API, Maps API nebo Gmail API.
  </Step>
  <Step title="Propojte své aplikace prostřednictvím API">
    Vygenerujte přihlašovací údaje k API v Cloud Console a pomocí rozhraní REST nebo klientských knihoven Googlu integrujte služby Google přímo do své aplikace. Podívejte se na [Rychlý start](/quickstart) a proveďte své první volání API během několika minut.
  </Step>
</Steps>
