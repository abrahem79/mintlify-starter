本快速开始将引导你完成登录 Google、获取 API 凭据以及发起首次 API 请求的整个过程——全部在 10 分钟内完成。结束时，你将拥有一个可正常返回实时搜索结果的 API 调用，可以在你自己的应用程序中进一步构建。

## 先决条件

在开始之前，请确保你具备以下条件：

- 一个 **Google 账户** — 如果你还没有，[免费创建一个](https://accounts.google.com/signup)。
- **基本的 HTTP 知识** — 熟悉发起 GET/POST 请求并读取 JSON 响应。
- 一个命令行终端或 HTTP 客户端，例如 [curl](https://curl.se/) 或 [Postman](https://www.postman.com/)。

## 步骤

<Steps>
  <Step title="登录">
    前往 [accounts.google.com](https://accounts.google.com) 并使用你的 Google 账户登录。如果这是你第一次使用，请先完成账户创建流程再继续。
  </Step>
  <Step title="获取 API 凭据">
    1. 打开 [Google Cloud Console](https://console.cloud.google.com)。
    2. 创建一个新项目（或选择一个现有项目）。
    3. 导航至 **APIs & Services → Library** 并启用 **Custom Search API**。
    4. 前往 **APIs & Services → Credentials**，然后点击 **Create Credentials → API key**。
    5. 复制你新的 API 密钥并妥善保存。
    6. 在 [programmablesearchengine.google.com](https://programmablesearchengine.google.com) 创建一个 Programmable Search Engine，并复制你的 **Search Engine ID**（`cx`）。
  </Step>
  <Step title="发起你的首次请求">
    将下面命令中的 `YOUR_API_KEY` 和 `YOUR_SEARCH_ENGINE_ID` 替换为你刚复制的值，然后在终端中运行它：

    ```bash
    curl -X GET "https://www.googleapis.com/customsearch/v1?q=hello+world&key=YOUR_API_KEY&cx=YOUR_SEARCH_ENGINE_ID"
    ```
  </Step>
  <Step title="检查响应">
    成功的请求会返回一个包含搜索元数据和结果数组的 JSON 对象。你应该会看到类似如下的响应：

    ```json
    {
      "kind": "customsearch#search",
      "url": {
        "type": "application/json",
        "template": "https://www.googleapis.com/customsearch/v1?q={searchTerms}&..."
      },
      "queries": {
        "request": [
          {
            "title": "Google Custom Search - hello world",
            "totalResults": "4970000000",
            "searchTerms": "hello world",
            "count": 10,
            "startIndex": 1
          }
        ]
      },
      "items": [
        {
          "kind": "customsearch#result",
          "title": "Hello, World! – Wikipedia",
          "htmlTitle": "\u003cb\u003eHello, World!\u003c/b\u003e – Wikipedia",
          "link": "https://en.wikipedia.org/wiki/%22Hello,_World!%22_program",
          "snippet": "A \"Hello, World!\" program is generally a simple computer program that outputs the phrase \"Hello, World!\" to a display device."
        }
      ]
    }
    ```

    `items` 数组包含你的搜索结果。每个对象都包含页面标题、URL（`link`）和一段简短的 `snippet`，你可以直接在 UI 中显示它们。
  </Step>
</Steps>

<Tip>
  上面的示例使用简单的 API 密钥进行身份验证。Google API 也支持 OAuth 2.0，用于访问用户数据的请求。有关所有受支持身份验证方法的完整说明，请参阅 [身份验证指南](/api/authentication)。
</Tip>
