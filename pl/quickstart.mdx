Ten szybki start przeprowadzi Cię przez logowanie do Google, uzyskanie poświadczeń API oraz wykonanie pierwszego wywołania API — wszystko w niecałe 10 minut. Na koniec będziesz mieć działające wywołanie API zwracające rzeczywiste wyniki wyszukiwania, które możesz rozbudować we własnej aplikacji.

## Wymagania wstępne

Zanim zaczniesz, upewnij się, że masz następujące elementy:

- **Konto Google** — [utwórz je bezpłatnie](https://accounts.google.com/signup), jeśli jeszcze go nie masz.
- **Podstawową znajomość HTTP** — obeznanie z wykonywaniem żądań GET/POST i odczytywaniem odpowiedzi JSON.
- Terminal wiersza poleceń lub klient HTTP, taki jak [curl](https://curl.se/) czy [Postman](https://www.postman.com/).

## Kroki

<Steps>
  <Step title="Zaloguj się">
    Wejdź na [accounts.google.com](https://accounts.google.com) i zaloguj się na swoje konto Google. Jeśli robisz to po raz pierwszy, przed dalszymi krokami przejdź proces zakładania konta.
  </Step>
  <Step title="Uzyskaj poświadczenia API">
    1. Otwórz [Google Cloud Console](https://console.cloud.google.com).
    2. Utwórz nowy projekt (lub wybierz istniejący).
    3. Przejdź do **APIs & Services → Library** i włącz **Custom Search API**.
    4. Otwórz **APIs & Services → Credentials** i kliknij **Create Credentials → API key**.
    5. Skopiuj nowy klucz API i zapisz go w bezpiecznym miejscu.
    6. Utwórz Programmable Search Engine na [programmablesearchengine.google.com](https://programmablesearchengine.google.com) i skopiuj identyfikator swojego **Search Engine ID** (`cx`).
  </Step>
  <Step title="Wykonaj pierwsze żądanie">
    Zamień `YOUR_API_KEY` i `YOUR_SEARCH_ENGINE_ID` w poniższym poleceniu na skopiowane wartości, a następnie uruchom je w terminalu:

    ```bash
    curl -X GET "https://www.googleapis.com/customsearch/v1?q=hello+world&key=YOUR_API_KEY&cx=YOUR_SEARCH_ENGINE_ID"
    ```
  </Step>
  <Step title="Sprawdź odpowiedź">
    Pomyślne żądanie zwraca obiekt JSON zawierający metadane wyszukiwania i tablicę wyników. Powinieneś zobaczyć odpowiedź podobną do tej:

    ```json
    {
      "kind": "customsearch#search",
      "url": {
        "type": "application/json",
        "template": "https://www.googleapis.com/customsearch/v1?q={searchTerms}&..."
      },
      "queries": {
        "request": [
          {
            "title": "Google Custom Search - hello world",
            "totalResults": "4970000000",
            "searchTerms": "hello world",
            "count": 10,
            "startIndex": 1
          }
        ]
      },
      "items": [
        {
          "kind": "customsearch#result",
          "title": "Hello, World! – Wikipedia",
          "htmlTitle": "\u003cb\u003eHello, World!\u003c/b\u003e – Wikipedia",
          "link": "https://en.wikipedia.org/wiki/%22Hello,_World!%22_program",
          "snippet": "A \"Hello, World!\" program is generally a simple computer program that outputs the phrase \"Hello, World!\" to a display device."
        }
      ]
    }
    ```

    Tablica `items` zawiera wyniki wyszukiwania. Każdy obiekt obejmuje tytuł strony, adres URL (`link`) i krótki fragment (`snippet`), który możesz wyświetlić bezpośrednio w swoim interfejsie.
  </Step>
</Steps>

<Tip>
  Powyższy przykład używa prostego klucza API do uwierzytelniania. Interfejsy API Google obsługują także OAuth 2.0 dla żądań uzyskujących dostęp do danych użytkownika. Zobacz [Przewodnik po uwierzytelnianiu](/api/authentication), aby zapoznać się z pełnym opisem wszystkich obsługiwanych metod uwierzytelniania.
</Tip>
