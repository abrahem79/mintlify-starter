---

قبل أن تتمكن من استخدام واجهات مطوري Google البرمجية، تحتاج إلى حساب Google، ومشروع Cloud لاستضافة مواردك، ومجموعة من بيانات الاعتماد التي سيستخدمها تطبيقك للمصادقة. يرشدك هذا الدليل خلال كل خطوة من هذه الخطوات حتى تكون جاهزًا لإجراء أول استدعاء لواجهة API.

## خطوات الإعداد

<Steps>
  <Step title="أنشئ حساب Google">
    إذا لم يكن لديك حساب Google بالفعل، فانتقل إلى [accounts.google.com/signup](https://accounts.google.com/signup) وأكمل نموذج التسجيل. يمنحك حساب Google الخاص بك الوصول إلى كل خدمة Google، بما في ذلك Cloud Console وGmail وDrive وجميع واجهات المطورين البرمجية.
  </Step>
  <Step title="انتقل إلى Google Cloud Console">
    انتقل إلى [Google Cloud Console](https://console.cloud.google.com) وسجّل الدخول باستخدام حساب Google الخاص بك. Console هو محورك المركزي لإدارة مشاريع Google Cloud، وتفعيل واجهات API، وإنشاء بيانات الاعتماد.
  </Step>
  <Step title="إنشاء مشروع">
    1. انقر على محدد المشروع في أعلى صفحة Console.
    2. انقر على **New Project**.
    3. أدخل **اسم مشروع** وصفيًا (على سبيل المثال، `my-search-app`).
    4. حدد **حساب فوترة** إذا طُلب منك، ثم انقر على **Create**.

    ستكون نطاق جميع واجهات API وبيانات الاعتماد التي تنشئها ضمن هذا المشروع، مما يجعل من السهل إدارة الاستخدام والفوترة بشكل منفصل لكل تطبيق.
  </Step>
  <Step title="تفعيل واجهات API">
    1. في التنقل الأيسر، انتقل إلى **APIs & Services → Library**.
    2. ابحث عن واجهة API التي تريد استخدامها (على سبيل المثال، **Custom Search API** أو **Maps JavaScript API** أو **Gmail API**).
    3. انقر على اسم API، ثم انقر على **Enable**.

    كرر هذه الخطوة لكل واجهة Google API يحتاجها تطبيقك. يمكن فقط لواجهات API المفعّلة تلقي الطلبات من بيانات اعتمادك.
  </Step>
  <Step title="إنشاء بيانات الاعتماد (مفتاح API)">
    1. انتقل إلى **APIs & Services → Credentials**.
    2. انقر على **Create Credentials** وحدد **API key**.
    3. يقوم Google بإنشاء مفتاح API جديد على الفور. انقر على **Copy** لنسخه إلى الحافظة الخاصة بك.
    4. اختياريًا، انقر على **Edit API key** لتقييد المفتاح لواجهات API محددة أو لمراجع HTTP وعناوين IP — يُنصح بشدة بذلك للاستخدام في الإنتاج.

    خزّن مفتاح API الخاص بك في موقع آمن مثل متغير بيئة أو مدير أسرار.
  </Step>
</Steps>

<Note>
  **احتفظ بسرية مفتاح API الخاص بك.** لا تلتزم أبدًا بمفتاح API في نظام التحكم بالمصدر أو تكشفه في الكود من جانب العميل. إذا تم اختراق مفتاحك، فانتقل إلى **APIs & Services → Credentials** في Cloud Console، وحذف المفتاح المتأثر، وأنشئ مفتاحًا جديدًا على الفور.
</Note>
