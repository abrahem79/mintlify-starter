在你可以使用 Google 的开发者 API 之前，你需要一个 Google 账户、一个用于承载资源的 Cloud 项目，以及一组供你的应用用于身份验证的凭据。本指南将带你完成每个步骤，让你为发起第一次 API 调用做好准备。

## 设置步骤

<Steps>
  <Step title="创建 Google 账户">
    如果你还没有 Google 账户，请前往 [accounts.google.com/signup](https://accounts.google.com/signup) 完成注册表。你的 Google 账户使你能够访问每一项 Google 服务，包括 Cloud Console、Gmail、Drive 以及所有开发者 API。
  </Step>
  <Step title="前往 Google Cloud Console">
    导航到 [Google Cloud Console](https://console.cloud.google.com) 并使用你的 Google 账户登录。Console 是你管理 Google Cloud 项目、启用 API 和创建凭据的中心枢纽。
  </Step>
  <Step title="创建项目">
    1. 点击 Console 页面顶部的项目选择器。
    2. 点击 **New Project**。
    3. 输入一个描述性的**项目名称**（例如 `my-search-app`）。
    4. 如果提示，请选择一个**结算账户**，然后点击 **Create**。

    你创建的所有 API 和凭据都将限定在此项目内，从而更容易分别管理每个应用的用量和结算。
  </Step>
  <Step title="启用 API">
    1. 在左侧导航中，前往 **APIs & Services → Library**。
    2. 搜索你想要使用的 API（例如 **Custom Search API**、**Maps JavaScript API** 或 **Gmail API**）。
    3. 点击 API 名称，然后点击 **Enable**。

    对你的应用所需的每个 Google API 重复此步骤。只有已启用的 API 才能接收来自你凭据的请求。
  </Step>
  <Step title="创建凭据（API 密钥）">
    1. 前往 **APIs & Services → Credentials**。
    2. 点击 **Create Credentials** 并选择 **API key**。
    3. Google 会立即生成一个新的 API 密钥。点击 **Copy** 将其复制到剪贴板。
    4. 可选地，点击 **Edit API key** 将密钥限制为特定 API、HTTP 引荐来源和 IP 地址——生产使用强烈建议这么做。

    将你的 API 密钥存储在安全位置，例如环境变量或密钥管理服务中。
  </Step>
</Steps>

<Note>
  **保密你的 API 密钥。** 切勿将 API 密钥提交到源代码管理或暴露在客户端代码中。如果你的密钥被泄露，请在 Cloud Console 中前往 **APIs & Services → Credentials**，立即删除受影响的密钥并生成新的密钥。
</Note>
