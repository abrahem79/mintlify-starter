Descreva como alguém começa a usar seu produto. Qual é a primeira coisa que precisa fazer? Existem pré-requisitos?

Um início rápido deve levar a pessoa do zero até o uso do seu produto. Ela terá uma vitória rápida e uma noção do que pode realizar.

## Pré-requisitos

Antes de começar, você precisa ter:

- Requisito um (por exemplo, Node.js 18+, uma conta gratuita, uma chave de API)
- Requisito dois (por exemplo, um dispositivo compatível, um navegador compatível, um sistema operacional compatível)

## Comece agora

<Steps>
  <Step title="Instalar">
    Descreva como instalar seu produto ou se cadastrar.

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="Configurar">
    Descreva qualquer configuração necessária antes do primeiro uso.

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="Executar">
    Mostre a primeira coisa que uma pessoa usuária faz para ver o produto funcionando.

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  Ofereça uma forma de obter ajuda. Pode ser um link para uma página de suporte, um chat com um agente de atendimento ou um fórum do seu produto.

  Exemplo: Precisa de ajuda? Entre em contato conosco em [support@yourcompany.com](mailto:support@yourcompany.com).
</Tip>
