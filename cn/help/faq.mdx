无论你是 Google 的新用户，还是与 Google API 打过多年交道的资深开发者，你都可能会遇到有关账户、存储、计费和访问控制如何运作的问题。本页汇集了 Google 消费级产品、Workspace 应用和开发者平台上最常见的问题解答——让你无需在多个帮助中心之间跳转即可快速找到答案。

<AccordionGroup>
  <Accordion title="如何重置我的 Google 密码？">
    你可以在账户恢复页面 [accounts.google.com/signin/recovery](https://accounts.google.com/signin/recovery) 重置你的 Google 密码。输入与你的账户关联的电子邮箱地址并按照提示操作——Google 会将验证代码发送到你的备用邮箱或电话号码。验证完成后，你就可以创建新密码。如果你已经无法访问所有恢复选项，Google 会提供一个身份验证流程，根据你的账户历史向你提问以确认身份。
  </Accordion>

  <Accordion title="为什么我的 API 密钥不工作？">
    API 密钥停止工作最常见的原因是：密钥被限制为特定的 IP 地址或引用来源，但与你当前的环境不匹配；密钥所在的 Google Cloud 项目未启用相应的 API；或者密钥已被删除或重新生成。请打开 [Google Cloud Console](https://console.cloud.google.com)，导航至 **APIs & Services → Credentials**，验证你密钥的限制和状态。同时确认目标 API（例如 Maps JavaScript API、Sheets API）已在 **APIs & Services → Enabled APIs & services** 下启用。
  </Accordion>

  <Accordion title="什么会计入我的 Google 存储配额？">
    你的 15 GB 免费 Google 存储由 Gmail（邮件和附件）、Google Drive（上传的文件）和 Google Photos（备份的图像和视频）共享。在 Google 原生格式中创建的 Google Docs、Sheets、Slides、Forms 和 Drawings **不** 会计入你的配额。然而，以其他格式上传到 Drive 的文件——例如 `.docx`、`.xlsx` 或 `.pdf`——会占用存储。你可以在 [one.google.com/storage](https://one.google.com/storage) 查看当前使用情况和明细。
  </Accordion>

  <Accordion title="如何删除我的 Google 账户？">
    你可以在账户设置的 **Data & privacy** 部分永久删除你的 Google 账户。前往 [myaccount.google.com](https://myaccount.google.com)，点击 **Data & privacy**，滚动到 **More options**，然后点击 **Delete your Google Account**。Google 会先请你使用 Google Takeout 下载数据的副本。请注意，删除是永久性的——你的 Gmail、Drive 文件和所有关联数据将丢失，宽限期过后无法恢复。
  </Accordion>

  <Accordion title="我可以免费使用 Google API 吗？">
    许多 Google API 提供了慷慨用量限制的免费额度——例如，Maps JavaScript API 每月包含 200 美元的免费额度，Google Sheets API 调用在每个项目的用量限制内免费。然而，高吞吐量使用、某些高级 API（如 Google Maps Routes Preferred）和企业级功能需要在 Google Cloud 中设置计费账户。你可以在 [cloud.google.com/pricing](https://cloud.google.com/pricing) 或各 API 的文档页面上查看任何特定 API 的定价。
  </Accordion>

  <Accordion title="如何转让 Google 文档的所有权？">
    要转让 Google Doc、Sheet 或 Slide 的所有权，请打开文件并点击右上角的 **Share**。找到你要转让给的人（他们必须已经有访问权限），点击其姓名旁的下拉菜单，选择 **Transfer ownership**。接收者将收到邮件通知，并且必须接受转让。请注意，你只能将所有权转让给同一 Google Workspace 组织中的另一位用户，或者对于个人账户，转让给另一位 Google 账户持有者。
  </Accordion>

  <Accordion title="如何在 Gmail 中举报垃圾邮件或钓鱼邮件？">
    要在 Gmail 中举报垃圾邮件，请打开该邮件，点击邮件右上角的 **三点菜单**（⋮），然后选择 **Report spam** 或 **Report phishing**。举报钓鱼邮件会将该邮件发送给 Google 审核，并帮助保护其他用户免受类似攻击。Gmail 还会自动将该邮件移出你的收件箱。如果你收到冒充某公司或机构的钓鱼邮件，还可以将其额外举报给 [Google Safe Browsing 团队](https://safebrowsing.google.com/safebrowsing/report_phish/)。
  </Accordion>

  <Accordion title="Google Search API 的速率限制是多少？">
    Google Custom Search JSON API 每天最多免费允许 **100 次搜索查询**，超出部分为每 1,000 次查询 5 美元（每天最多 10,000 次）。这适用于 Programmable Search Engine API——如果你使用的是 Google Search Console API 或其他搜索相关的 API，则限制不同并单独记录。你可以在 [Google Cloud Console](https://console.cloud.google.com) 的 **APIs & Services → Quotas** 中监控用量并配置请求配额。对于非常高吞吐量的搜索需求，Google 通过 Google Cloud 提供企业级选项。
  </Accordion>
</AccordionGroup>
