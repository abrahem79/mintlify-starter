title: "Démarrage rapide"
description: "Commencez par un guide qui vous mène le plus rapidement possible à un résultat concluant"
---

Décrivez comment un utilisateur commence à utiliser votre produit. Quelle est la première chose qu'il doit faire? Y a-t-il des prérequis?

Un démarrage rapide doit permettre à une personne de passer de zéro à l'utilisation de votre produit. Elle obtiendra une victoire rapide et une bonne idée de ce qu'elle peut accomplir.

## Prérequis

Avant de commencer, vous devez avoir :

- Exigence numéro un (par exemple, Node.js 18+, un compte gratuit, une clé API)
- Exigence numéro deux (par exemple, un appareil compatible, un navigateur compatible, un système d'exploitation compatible)

## Pour commencer

<Steps>
  <Step title="Installer">
    Décrivez comment installer votre produit ou s'y inscrire.

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="Configurer">
    Décrivez toute étape d'installation ou de configuration nécessaire avant la première utilisation.

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="Lancer">
    Montrez la première chose qu'un utilisateur fait pour voir le produit fonctionner.

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  Offrez aux utilisateurs un moyen d'obtenir de l'aide. Cela peut être un lien vers une page d'assistance, une conversation avec un agent du service à la clientèle ou un forum dédié à votre produit.

  Exemple : Besoin d'aide? Contactez-nous à [support@yourcompany.com](mailto:support@yourcompany.com).
</Tip>
