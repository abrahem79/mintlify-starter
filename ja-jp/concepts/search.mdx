Google Search は毎年数千億ページを処理し、数兆件のクエリに答える、世界で最も広く使われている情報検索システムです。ご自身の検索テクニックを磨きたい場合でも、Google が正しく表示できるようにコンテンツを最適化したい場合でも、自社製品に検索機能を直接埋め込む場合でも、Search の内部の仕組みを理解することは大きな優位性をもたらします。

## Search の仕組み

Google Search は、バックグラウンドで継続的に実行される 3 つの大きなステージで動作します。

**クロール** — Google の自動クローラー(総称して Googlebot)がウェブ全体でリンクをたどり、新規および更新されたページを発見します。`robots.txt` ファイルと `<meta name="robots">` タグを使って、クローラーが何を取得するかを制御できます。

**インデックス化** — ページがクロールされると、Google はそのコンテンツ(テキスト、画像、構造化データなど)を分析し、その表現を Search インデックスに保存します。明確な見出し、記述的なメタデータ、有効なスキーママークアップを持つ、構造化されたページは、より正確にインデックス化されやすくなります。

**ランキング** — ユーザーがクエリを送信すると、Google のランキングシステムが数百のシグナル(関連性、ページ品質、コンテキスト、鮮度など)を評価して結果を順位付けします。単一の要素だけでランクが決まることはなく、アルゴリズムはシグナルを総合的に重み付けし、そのクエリに最も有用な結果を表示します。

<Note>
  Google はすべてのページのインデックス化を保証していません。Google Search Console を使用して、カバレッジを監視し、クロールエラーを特定し、重要な URL の(再)インデックス化をリクエストしてください。
</Note>

## 検索演算子

検索演算子は、Google Search ボックスに直接入力して結果をフィルタリング・絞り込みするための特殊なコマンドです。リサーチ、競合分析、自社サイトのプレゼンス監査、インデックス化問題のデバッグに便利です。

| 演算子 | 構文 | 動作 |
|---|---|---|
| `site:` | `site:example.com` | 結果を特定のドメインまたはサブドメイン上のページに制限します。 |
| `filetype:` | `filetype:pdf` | 特定のファイルタイプ(pdf、docx、xlsx など)の結果を返します。 |
| `intitle:` | `intitle:keyword` | HTML の `<title>` タグにキーワードを含むページを一致させます。 |
| 完全一致フレーズ | `"machine learning"` | その正確な語順を含む結果のみを返します。 |
| 除外語 | `-keyword` | 指定した語やフレーズを含む結果を除外します。 |

演算子は 1 つのクエリ内で組み合わせて使えます。例えば、`site:docs.example.com filetype:pdf -intitle:archive` は、あなたのドキュメントサブドメイン上にあり、タイトルに「archive」を含まない PDF ファイルを検索します。

<Tip>
  演算子の前に `OR`(大文字)を付けると、2 つの条件のいずれかにマッチします — 例えば、`site:example.com OR site:example.io` は 1 つのクエリで両方のドメインから結果を返します。
</Tip>

## Custom Search Engine(CSE)

Custom Search Engine を使用すると、ウェブ全体ではなく特定のサイトやページのセットをクエリする、スコープを絞ったブランド化された検索体験を作成できます。これは、ドキュメント、ヘルプセンター、または EC カタログに検索バーを追加する際に便利です。

**Custom Search Engine を作成するには:**

1. [Programmable Search Engine コントロールパネル](https://programmablesearchengine.google.com/controlpanel/all) にアクセスします。
2. **Add** をクリックし、検索したいサイトまたは URL パターンを入力します。
3. エンジンに名前を付けて保存します — Google はエンジンを識別する一意の **Search Engine ID**(`cx` パラメーター)を生成します。
4. **Look and feel** で見た目をカスタマイズし、埋め込みスニペットをページにコピーします。

<Note>
  CSE の結果は、通常の Google Search と同じインデックス化ルールに従います。ページがインデックス化されていない場合、CSE の結果にも表示されません。
</Note>

## Programmable Search API

Programmable Search JSON API は、Custom Search Engine の結果へのプログラマティックなアクセスを提供するため、Google の UI を埋め込むことなく、独自のアプリケーション内で結果を取得、整形、表示できます。

主要な機能:

- CSE にクエリを送り、タイトル、URL、スニペット、リッチメタデータを含む構造化 JSON レスポンスを受け取ります。
- `dateRestrict`、`sort`、`filter` パラメーターをリクエスト時に適用して結果を絞り込みます。
- `searchType=image` パラメーターを使って、定義したスコープ内で画像を検索します。

完全なリクエスト/レスポンスのスキーマ、認証要件、コードサンプルについては、[Search API リファレンス](/api/search) を参照してください。
