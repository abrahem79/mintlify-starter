Aprakstiet, kā kāds sāk lietot jūsu produktu. Kas ir pirmais, kas viņiem jādara? Vai ir kādi priekšnosacījumi?

Ātrajam sākumam vajadzētu aizvest lietotāju no nulles līdz jūsu produkta lietošanai. Viņi ātri gūs panākumus un sapratīs, ko var paveikt.

## Priekšnosacījumi

Pirms sākat, jums ir nepieciešams:

- Pirmā prasība (piemēram, Node.js 18+, bezmaksas konts, API atslēga)
- Otrā prasība (piemēram, saderīga ierīce, saderīgs pārlūks, saderīga operētājsistēma)

## Sāciet darbu

<Steps>
  <Step title="Instalēšana">
    Aprakstiet, kā instalēt jūsu produktu vai reģistrēties.

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="Konfigurēšana">
    Aprakstiet iestatīšanu vai konfigurāciju, kas nepieciešama pirms pirmās lietošanas.

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="Palaidiet to">
    Parādiet pirmo darbību, ko lietotājs veic, lai redzētu, ka viss darbojas.

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  Piedāvājiet cilvēkiem veidu, kā saņemt palīdzību. Tā var būt saite uz atbalsta lapu, saruna ar klientu atbalsta pārstāvi vai forums par jūsu produktu.

  Piemērs: Vai nepieciešama palīdzība? Sazinieties ar mums, rakstot uz [support@yourcompany.com](mailto:support@yourcompany.com).
</Tip>
