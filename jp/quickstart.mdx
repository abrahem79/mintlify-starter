---
title: "クイックスタート"
description: "成功への最短ルートを示すガイドから始めましょう"
---

利用者が製品を使い始める方法を説明します。最初に何をする必要がありますか？前提条件はありますか？

クイックスタートは、利用者をゼロから製品の利用開始まで導くものです。素早い成功体験を得て、何ができるのかを実感してもらえるようにしましょう。

## 前提条件

始める前に、以下が必要です:

- 要件その 1 (例: Node.js 18 以上、無料アカウント、API キー)
- 要件その 2 (例: 対応デバイス、対応ブラウザ、対応オペレーティングシステム)

## 始めましょう

<Steps>
  <Step title="インストール">
    製品のインストール方法やサインアップの方法を説明します。

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="設定">
    初回利用の前に必要なセットアップや設定について説明します。

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="実行する">
    利用者が動作を確認するために最初に行う操作を示します。

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  ヘルプを得られる手段を用意しましょう。サポートページへのリンク、カスタマーサポートとのチャット、製品のフォーラムなどが考えられます。

  例: お困りですか？[support@yourcompany.com](mailto:support@yourcompany.com) までお問い合わせください。
</Tip>
