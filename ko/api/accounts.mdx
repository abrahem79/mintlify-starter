Google은 인증된 사용자의 신원 및 프로필 데이터를 읽기 위한 두 가지 상호 보완적인 엔드포인트를 제공합니다. OAuth 2.0 userinfo 엔드포인트는 이메일, 표시 이름, 프로필 사진, 로케일 등 가벼운 요약을 제공하며 로그인 흐름에 적합합니다. People API는 사용자의 연락처 레코드에 대한 더 풍부하고 구조화된 뷰를 제공하며, 세밀한 필드 제어가 필요할 때 적합합니다. 두 엔드포인트 모두 적절한 스코프를 가진 유효한 OAuth 2.0 액세스 토큰이 필요합니다.

<Note>
  이 페이지에 설명된 두 엔드포인트는 유효한 OAuth 2.0 Bearer 토큰이 필요합니다. API 키는 **허용되지 않습니다** — 이 리소스들은 인증된 사용자 신원에 연결되어 있습니다. OAuth 흐름을 설정하려면 [Authentication 가이드](/api/authentication)를 참조하세요.
</Note>

## 현재 사용자 프로필 가져오기

현재 인증된 사용자의 간결한 프로필을 조회합니다.

**엔드포인트**

```http
GET https://www.googleapis.com/oauth2/v2/userinfo
```

**필요한 스코프:** `openid email profile`

### 요청 예시

```bash
curl -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  "https://www.googleapis.com/oauth2/v2/userinfo"
```

### 응답 예시

```json
{
  "id": "116195079999551234567",
  "email": "alex@example.com",
  "name": "Alex Johnson",
  "given_name": "Alex",
  "family_name": "Johnson",
  "picture": "https://lh3.googleusercontent.com/a/ACg8ocJ...",
  "locale": "en"
}
```

### 응답 필드

<ResponseField name="id" type="string">
  사용자의 고유하고 안정적인 Google 계정 ID입니다. 사용자가 이메일 주소나 이름을 업데이트하더라도 이 값은 변경되지 않습니다.
</ResponseField>

<ResponseField name="email" type="string">
  사용자의 주 Google 계정 이메일 주소입니다. `email` 스코프가 필요합니다.
</ResponseField>

<ResponseField name="name" type="string">
  Google 계정에 표시되는 사용자의 전체 표시 이름입니다.
</ResponseField>

<ResponseField name="given_name" type="string">
  사용자의 이름(given name)입니다. `profile` 스코프가 필요합니다.
</ResponseField>

<ResponseField name="family_name" type="string">
  사용자의 성(family name)입니다. `profile` 스코프가 필요합니다.
</ResponseField>

<ResponseField name="picture" type="string">
  Google 서버에서 호스팅되는 사용자의 프로필 사진을 가리키는 URL입니다. 이미지는 공개적으로 접근 가능하지만 사용자가 사진을 업데이트하면 변경될 수 있습니다.
</ResponseField>

<ResponseField name="locale" type="string">
  사용자의 선호 언어를 나타내는 BCP 47 언어 태그입니다(예: `"en"`, `"fr"`, `"ja"`). `profile` 스코프가 필요합니다.
</ResponseField>

## People API를 통해 사용자 정보 가져오기

People API는 더 풍부한 구조화된 데이터를 반환하며, `personFields` 파라미터를 사용해 필요한 필드만 정확히 요청할 수 있게 해줍니다.

**엔드포인트**

```http
GET https://people.googleapis.com/v1/people/me?personFields=names,emailAddresses
```

**필요한 스코프:** `https://www.googleapis.com/auth/contacts.readonly`

### 요청 예시

```bash
curl -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  "https://people.googleapis.com/v1/people/me?personFields=names,emailAddresses"
```

### 응답 예시

```json
{
  "resourceName": "people/116195079999551234567",
  "etag": "%EgoBAgkLDg8REhMaAQ==",
  "names": [
    {
      "displayName": "Alex Johnson",
      "givenName": "Alex",
      "familyName": "Johnson",
      "metadata": {
        "primary": true,
        "source": { "type": "PROFILE" }
      }
    }
  ],
  "emailAddresses": [
    {
      "value": "alex@example.com",
      "metadata": {
        "primary": true,
        "verified": true
      }
    }
  ]
}
```

<Tip>
  `phoneNumbers`, `addresses`, `birthdays`, `photos` 같은 추가 `personFields`를 쉼표로 구분한 목록으로 덧붙여 요청할 수 있습니다: `?personFields=names,emailAddresses,phoneNumbers`.
</Tip>
