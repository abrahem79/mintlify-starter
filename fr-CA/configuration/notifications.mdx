Google fait remonter les notifications par plusieurs canaux — fenêtres surgissantes sur le bureau, alertes poussées mobiles et résumés par courriel — pour vous tenir informé de l'activité dans Gmail, Drive, Calendar et d'autres services. Bien gérer ces paramètres vous aide à demeurer productif sans être submergé par des interruptions inutiles. Chaque service Google possède ses propres contrôles de notifications, et vous pouvez les ajuster finement de façon indépendante.

## Aperçu des paramètres de notifications

Le tableau ci-dessous vous donne une référence rapide sur l'endroit où configurer les notifications pour chaque service Google majeur :

| Service | Type de notification | Où configurer |
|---|---|---|
| **Gmail** | Fenêtres surgissantes de bureau, notifications poussées mobiles | Gmail → icône d'engrenage Paramètres → Afficher tous les paramètres → Général → Notifications de bureau |
| **Google Drive** | Partage, commentaires, activité de modification | Drive → icône d'engrenage Paramètres → Notifications |
| **Google Calendar** | Rappels d'événements, courriel vs fenêtre surgissante | Calendar → icône d'engrenage Paramètres → Paramètres → [Événement] → Notifications |
| **Navigateur (Chrome)** | Notifications poussées par site | Chrome → Paramètres → Confidentialité et sécurité → Paramètres de sites → Notifications |
| **Google Meet** | Alertes d'appel entrant | Meet → Paramètres → Notifications |

## Notifications Gmail

Gmail peut vous avertir chaque fois qu'un nouveau courriel arrive — soit sur votre bureau pendant que vous utilisez Chrome, soit sur votre appareil mobile via des notifications poussées. Vous pouvez choisir d'être averti pour tous les nouveaux courriels ou seulement pour les messages importants.

### Notifications de bureau

<Steps>
  <Step title="Ouvrir les paramètres Gmail">
    Dans Gmail, cliquez sur l'icône **d'engrenage Paramètres** dans le coin supérieur droit, puis cliquez sur **Afficher tous les paramètres**.
  </Step>
  <Step title="Aller à l'onglet Général">
    L'onglet **Général** s'ouvre par défaut. Faites défiler jusqu'à la section **Notifications de bureau**.
  </Step>
  <Step title="Choisir votre niveau de notification">
    Sélectionnez l'une des options suivantes :
    - **Notifications de courriel désactivées** — aucune alerte de bureau
    - **Notifications de courriels importants activées** — alertes seulement pour les courriels que Gmail marque comme importants
    - **Notifications de nouveaux courriels activées** — alertes pour chaque nouveau message
  </Step>
  <Step title="Accorder la permission au navigateur si demandé">
    S'il s'agit de la première fois que vous activez les notifications de bureau, votre navigateur demandera la permission. Cliquez sur **Autoriser** pour continuer.
  </Step>
  <Step title="Enregistrer les modifications">
    Faites défiler jusqu'au bas de la page Paramètres et cliquez sur **Enregistrer les modifications**.
  </Step>
</Steps>

### Notifications poussées mobiles

Pour gérer les notifications poussées Gmail sur un appareil mobile, ouvrez l'**application Gmail**, touchez votre photo de profil, allez à **Gérer votre compte Google**, puis accédez aux paramètres de notification intégrés de l'application Gmail sous **Paramètres → [Votre compte] → Notifications**.

<Note>
  Sur Android, vous pouvez aussi contrôler le comportement des notifications Gmail directement dans les paramètres système de votre appareil sous **Applications → Gmail → Notifications**.
</Note>

## Notifications Google Drive

Google Drive peut vous avertir lorsque des collaborateurs partagent des fichiers avec vous, laissent des commentaires, suggèrent des modifications ou apportent des changements aux fichiers que vous possédez ou suivez.

<Steps>
  <Step title="Ouvrir les paramètres Drive">
    Dans Google Drive, cliquez sur l'icône **d'engrenage Paramètres** dans le coin supérieur droit, puis cliquez sur **Paramètres**.
  </Step>
  <Step title="Aller à Notifications">
    Dans la boîte de dialogue Paramètres, cliquez sur **Notifications** dans le panneau de gauche.
  </Step>
  <Step title="Basculer les types de notifications">
    Activez ou désactivez les notifications pour les événements suivants :
    - Quelqu'un partage un fichier avec vous
    - Quelqu'un commente votre fichier
    - Quelqu'un répond à votre commentaire
    - Quelqu'un demande l'accès à votre fichier
  </Step>
</Steps>

<Tip>
  Si vous voulez uniquement arrêter les notifications pour un seul fichier, ouvrez ce fichier, cliquez sur l'icône de cloche (🔔) près du haut, et sélectionnez **Toutes les notifications désactivées** pour ce document uniquement.
</Tip>

## Notifications Google Calendar

Google Calendar prend en charge deux types de rappels : les **fenêtres surgissantes** (alertes à l'écran) et les **notifications par courriel**. Vous pouvez définir des rappels par défaut qui s'appliquent à tous les nouveaux événements, et les remplacer événement par événement.

### Définir les notifications par défaut

<Steps>
  <Step title="Ouvrir les paramètres Calendar">
    Dans Google Calendar, cliquez sur l'icône **d'engrenage Paramètres** et sélectionnez **Paramètres**.
  </Step>
  <Step title="Sélectionner votre agenda">
    Dans la barre latérale gauche, sous **Paramètres pour mes agendas**, cliquez sur le nom de l'agenda que vous voulez configurer.
  </Step>
  <Step title="Faire défiler jusqu'à Notifications d'événements">
    Faites défiler jusqu'à la section **Notifications d'événements**.
  </Step>
  <Step title="Ajouter ou modifier les rappels">
    Cliquez sur **Ajouter une notification** et choisissez **Courriel** ou **Notification** (fenêtre surgissante), puis définissez le délai avant l'événement pour lequel vous voulez être rappelé (p. ex., 10 minutes, 1 jour).
  </Step>
</Steps>

### Notifications par événement

Lorsque vous créez ou modifiez un événement individuel, faites défiler jusqu'au champ **Ajouter une notification** au bas de l'éditeur d'événement. Vous pouvez ajouter plusieurs rappels par événement et mélanger les types courriel et fenêtre surgissante.

| Type de rappel | Mode de livraison | Idéal pour |
|---|---|---|
| **Fenêtre surgissante** | Alerte à l'écran dans le navigateur ou l'application mobile | Rappels rapides pour les événements plus tard dans la journée |
| **Courriel** | Envoyé à votre boîte de réception Gmail | Préavis pour les réunions importantes |

## Notifications poussées du navigateur

Chrome permet aux sites Web — y compris les services Google — d'envoyer des notifications poussées même lorsque vous ne visitez pas activement le site. Vous pouvez gérer ces permissions au niveau du navigateur.

<Steps>
  <Step title="Ouvrir les paramètres Chrome">
    Dans Chrome, cliquez sur le **menu à trois points** (⋮) dans le coin supérieur droit et sélectionnez **Paramètres**.
  </Step>
  <Step title="Aller aux Paramètres de sites">
    Cliquez sur **Confidentialité et sécurité** dans la barre latérale gauche, puis cliquez sur **Paramètres de sites**.
  </Step>
  <Step title="Ouvrir Notifications">
    Sous **Autorisations**, cliquez sur **Notifications**.
  </Step>
  <Step title="Gérer les permissions de notifications">
    Vous verrez une liste des sites autorisés ou bloqués pour l'envoi de notifications. Vous pouvez :
    - Basculer le comportement par défaut pour tous les sites
    - Ajouter un site précis à la liste **Autorisés** ou **Bloqués**
    - Retirer ou réinitialiser les permissions pour n'importe quelle entrée existante
  </Step>
</Steps>

<Warning>
  Certains services Google requièrent les permissions de notification du navigateur pour livrer des alertes en temps réel. Si vous bloquez toutes les notifications au niveau du navigateur, les alertes dans le navigateur pour Gmail, Calendar et Meet cesseront de fonctionner même si elles sont activées dans les paramètres de chaque application.
</Warning>
