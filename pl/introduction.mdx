## Jak to działa

Rozpoczęcie pracy z Google zajmuje zaledwie kilka minut. Wykonaj te trzy kroki, aby przejść od zera do pełnej integracji.

<Steps>
  <Step title="Utwórz konto Google">
    Odwiedź [accounts.google.com](https://accounts.google.com) i zarejestruj bezpłatne konto Google. Twoje konto jest przepustką do każdej usługi Google — wyszukiwarki, Gmaila, Dysku, Cloud i innych.
  </Step>
  <Step title="Włącz potrzebne usługi">
    Przejdź do [Google Cloud Console](https://console.cloud.google.com), aby utworzyć projekt i włączyć konkretne interfejsy API oraz usługi wymagane w Twoim przypadku użycia, takie jak Custom Search API, Maps API czy Gmail API.
  </Step>
  <Step title="Podłącz swoje aplikacje przez API">
    Wygeneruj poświadczenia API w Cloud Console i wykorzystaj interfejsy REST lub biblioteki klienckie Google, aby zintegrować usługi Google bezpośrednio z aplikacją. Zajrzyj do [Szybkiego startu](/quickstart), aby wykonać pierwsze wywołanie API w kilka minut.
  </Step>
</Steps>
