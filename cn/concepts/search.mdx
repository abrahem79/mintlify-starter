Google Search 每年处理数千亿个页面，回答数万亿次查询，是世界上使用最广泛的信息检索系统。无论你是在改进自己的搜索技巧、优化内容让 Google 能正确呈现，还是将搜索能力直接嵌入到你的产品中，理解 Search 底层的工作原理都能带来实质性的优势。

## Search 的工作方式

Google Search 在后台持续运行三个宏观阶段。

**抓取（Crawling）** — Google 的自动爬虫（统称为 Googlebot）跟随网络上的链接来发现新的和已更新的页面。你可以通过 `robots.txt` 文件和 `<meta name="robots">` 标签来引导爬虫，控制哪些内容被抓取。

**索引（Indexing）** — 一旦页面被抓取，Google 会分析其内容——文本、图像、结构化数据等——并将其表示存储到搜索索引中。具有清晰标题、描述性元数据和有效 schema 标记的结构良好的页面更容易被准确索引。

**排序（Ranking）** — 当用户提交查询时，Google 的排序系统会评估数百个信号（相关性、页面质量、上下文、时效性等）来对结果进行排序。没有单一因素决定排名；算法综合权衡这些信号，为该查询呈现最有用的结果。

<Note>
  Google 并不保证每个页面都会被索引。使用 Google Search Console 来监控收录情况、识别抓取错误，并为重要 URL 请求（重新）索引。
</Note>

## 搜索操作符

搜索操作符是你直接在 Google 搜索框中输入的特殊命令，用于过滤和缩小结果范围。它们对于研究、竞品分析、审计你自己网站的收录情况和调试索引问题非常有用。

| 操作符 | 语法 | 作用 |
|---|---|---|
| `site:` | `site:example.com` | 将结果限制在特定域名或子域名的页面。 |
| `filetype:` | `filetype:pdf` | 返回特定文件类型的结果（pdf、docx、xlsx 等）。 |
| `intitle:` | `intitle:keyword` | 匹配 HTML `<title>` 标签中包含关键词的页面。 |
| 精确短语 | `"machine learning"` | 仅返回包含该确切词序的结果。 |
| 排除词 | `-keyword` | 移除包含指定词或短语的结果。 |

你可以在一次查询中组合多个操作符。例如，`site:docs.example.com filetype:pdf -intitle:archive` 会在你的 docs 子域名上查找标题不含 "archive" 的 PDF 文件。

<Tip>
  在操作符前加 `OR`（大写）以匹配两个条件之一——例如，`site:example.com OR site:example.io` 会在一次查询中返回来自两个域名的结果。
</Tip>

## 自定义搜索引擎 (CSE)

自定义搜索引擎让你可以创建一个有范围的、带品牌的搜索体验，用于查询特定的一组网站或页面，而不是整个网络。这对于在文档、帮助中心或电商目录中添加搜索栏非常有用。

**创建自定义搜索引擎：**

1. 前往 [Programmable Search Engine 控制面板](https://programmablesearchengine.google.com/controlpanel/all)。
2. 点击 **Add** 并输入你要搜索的站点或 URL 模式。
3. 为引擎命名并保存——Google 会生成一个唯一的 **Search Engine ID**（`cx` 参数）来标识你的引擎。
4. 在 **Look and feel** 下自定义外观样式，然后将嵌入代码片段复制到你的页面。

<Note>
  CSE 结果遵循与常规 Google Search 相同的索引规则。如果某个页面未被索引，它也不会出现在你的 CSE 结果中。
</Note>

## Programmable Search API

Programmable Search JSON API 让你可以通过编程方式访问自定义搜索引擎的结果，从而完全在你自己的应用程序中检索、格式化并显示搜索结果——无需嵌入 Google 的 UI。

主要功能包括：

- 查询你的 CSE 并接收包含标题、URL、摘要和丰富元数据的结构化 JSON 响应。
- 应用 `dateRestrict`、`sort` 和 `filter` 参数在请求时精化结果。
- 使用 `searchType=image` 参数在你定义的范围内搜索图像。

有关完整的请求/响应架构、身份验证要求和代码示例，请参阅 [Search API 参考](/api/search)。
