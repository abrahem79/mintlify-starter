يرشدك دليل البدء السريع هذا خلال تسجيل الدخول إلى Google، والحصول على بيانات اعتماد API، وإجراء أول طلب لواجهة API — كل ذلك في أقل من 10 دقائق. بحلول النهاية، سيكون لديك استدعاء API يعمل ويعيد نتائج بحث مباشرة يمكنك البناء عليها في تطبيقك الخاص.

## المتطلبات الأساسية

قبل أن تبدأ، تأكد من توفر ما يلي:

- **حساب Google** — [أنشئ واحدًا مجانًا](https://accounts.google.com/signup) إذا لم يكن لديك واحد بعد.
- **معرفة HTTP الأساسية** — الإلمام بإجراء طلبات GET/POST وقراءة استجابات JSON.
- طرفية سطر أوامر أو عميل HTTP مثل [curl](https://curl.se/) أو [Postman](https://www.postman.com/).

## الخطوات

<Steps>
  <Step title="تسجيل الدخول">
    انتقل إلى [accounts.google.com](https://accounts.google.com) وسجّل الدخول باستخدام حساب Google الخاص بك. إذا كانت هذه هي المرة الأولى لك، فأكمل عملية إنشاء الحساب قبل المتابعة.
  </Step>
  <Step title="الحصول على بيانات اعتماد API">
    1. افتح [Google Cloud Console](https://console.cloud.google.com).
    2. أنشئ مشروعًا جديدًا (أو حدد مشروعًا موجودًا).
    3. انتقل إلى **APIs & Services → Library** وفعّل **Custom Search API**.
    4. انتقل إلى **APIs & Services → Credentials** وانقر على **Create Credentials → API key**.
    5. انسخ مفتاح API الجديد الخاص بك واحفظه في مكان آمن.
    6. أنشئ محرك بحث قابل للبرمجة على [programmablesearchengine.google.com](https://programmablesearchengine.google.com) وانسخ **معرّف محرك البحث** الخاص بك (`cx`).
  </Step>
  <Step title="إجراء أول طلب لك">
    استبدل `YOUR_API_KEY` و`YOUR_SEARCH_ENGINE_ID` في الأمر أدناه بالقيم التي نسختها، ثم شغّله في الطرفية:

    ```bash
    curl -X GET "https://www.googleapis.com/customsearch/v1?q=hello+world&key=YOUR_API_KEY&cx=YOUR_SEARCH_ENGINE_ID"
    ```
  </Step>
  <Step title="فحص الاستجابة">
    يعيد الطلب الناجح كائن JSON يحتوي على بيانات وصفية للبحث ومصفوفة من النتائج. من المفترض أن ترى استجابة مشابهة لهذه:

    ```json
    {
      "kind": "customsearch#search",
      "url": {
        "type": "application/json",
        "template": "https://www.googleapis.com/customsearch/v1?q={searchTerms}&..."
      },
      "queries": {
        "request": [
          {
            "title": "Google Custom Search - hello world",
            "totalResults": "4970000000",
            "searchTerms": "hello world",
            "count": 10,
            "startIndex": 1
          }
        ]
      },
      "items": [
        {
          "kind": "customsearch#result",
          "title": "Hello, World! – Wikipedia",
          "htmlTitle": "\u003cb\u003eHello, World!\u003c/b\u003e – Wikipedia",
          "link": "https://en.wikipedia.org/wiki/%22Hello,_World!%22_program",
          "snippet": "A \"Hello, World!\" program is generally a simple computer program that outputs the phrase \"Hello, World!\" to a display device."
        }
      ]
    }
    ```

    تحتوي مصفوفة `items` على نتائج البحث الخاصة بك. يشمل كل كائن عنوان الصفحة، وعنوان URL (`link`)، ومقتطفًا قصيرًا (`snippet`) يمكنك عرضه مباشرة في واجهة المستخدم لديك.
  </Step>
</Steps>

<Tip>
  يستخدم المثال أعلاه مفتاح API بسيطًا للمصادقة. تدعم واجهات Google البرمجية أيضًا OAuth 2.0 للطلبات التي تصل إلى بيانات المستخدم. راجع [دليل المصادقة](/api/authentication) للحصول على شرح كامل لجميع طرق المصادقة المدعومة.
</Tip>
