Google 플랫폼은 정보를 찾고, 만들고, 공유하는 전체 생애 주기를 아우르는 광범위한 클라우드 기반 서비스를 한데 모읍니다. 답을 얻기 위해 웹을 검색하든, 공유 문서에서 팀원과 협업하든, Google 인프라를 활용하는 애플리케이션을 만들든 — 모든 서비스는 원활하게 함께 작동하도록 설계되어 있어 개인, 팀, 개발자에게 구축할 일관된 기반을 제공합니다.

## Google 플랫폼의 세 가지 축

Google은 핵심 제공물을 서로 뚜렷하지만 상호 보완적인 세 가지 영역으로 구성합니다.

### 1. Search

Google Search는 매일 수십억 건의 쿼리를 위한 진입점입니다. 웹 검색을 넘어, Google의 검색 기술은 내부 도구, 여러분의 제품에 임베드된 맞춤형 검색 엔진, 그리고 프로그래밍 방식으로 정보를 조회하고 순위화할 수 있게 해주는 API를 지원합니다. Search가 어떻게 작동하는지 이해하면 — 사용자든 여러분 자신이든 — 적시에 올바른 콘텐츠를 노출하는 데 도움이 됩니다.

### 2. Google Workspace

Google Workspace는 Google의 클라우드 기반 생산성 및 협업 애플리케이션 제품군입니다. Gmail, Google Drive, Docs, Sheets, Slides, Meet를 포함하며, 모두 실시간 협업을 중심으로 구축되고 어떤 기기에서든 접근할 수 있습니다. Workspace는 팀 전체가 하나의 공유 환경에서 작업하고, 누가 콘텐츠를 볼 수 있는지, 댓글을 달 수 있는지, 편집할 수 있는지를 세밀하게 제어할 수 있도록 설계되었습니다.

### 3. 개발자 API

Google은 서비스에 대한 프로그래밍 방식 접근을 제공하는 풍부한 API 세트를 노출합니다 — 애플리케이션에 검색 결과를 임베드하는 것부터, Workspace 문서를 읽고 쓰는 것, 인증, 지도, 머신러닝 모델을 통합하는 것까지. API는 표준 REST 및 gRPC 규칙을 따르고, 인증에는 OAuth 2.0을 사용하며, 이 문서의 API 레퍼런스 섹션에 전부 문서화되어 있습니다.
