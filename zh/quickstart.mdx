介绍用户如何开始使用你的产品。他们首先需要做什么？是否有任何先决条件？

一个快速开始指南应该带用户从零上手使用你的产品。他们能够快速体验到成果，并了解可以用它完成什么。

## 先决条件

在开始之前，你需要具备：

- 要求一（例如，Node.js 18+、一个免费账户、一个 API 密钥）
- 要求二（例如，兼容的设备、兼容的浏览器、兼容的操作系统）

## 开始使用

<Steps>
  <Step title="安装">
    介绍如何安装你的产品或进行注册。

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="配置">
    介绍首次使用前所需的任何设置或配置。

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="运行">
    展示用户为查看运行效果所要做的第一件事。

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  为用户提供获取帮助的方式。这可以是一个指向支持页面的链接、与客服代表的聊天，或者是你产品的论坛。

  示例：需要帮助？请通过 [support@yourcompany.com](mailto:support@yourcompany.com) 联系我们。
</Tip>
