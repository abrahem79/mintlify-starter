Tento rychlý start vás provede přihlášením ke Googlu, získáním přihlašovacích údajů k API a odesláním prvního požadavku na API — to vše za méně než 10 minut. Na konci budete mít funkční volání API vracející živé výsledky vyhledávání, na kterém můžete stavět ve své vlastní aplikaci.

## Předpoklady

Než začnete, ujistěte se, že máte následující:

- **Účet Google** — [vytvořte si jej zdarma](https://accounts.google.com/signup), pokud jej ještě nemáte.
- **Základní znalost HTTP** — obeznámenost s odesíláním požadavků GET/POST a čtením odpovědí JSON.
- Terminál příkazového řádku nebo HTTP klienta, jako je [curl](https://curl.se/) nebo [Postman](https://www.postman.com/).

## Kroky

<Steps>
  <Step title="Přihlaste se">
    Přejděte na [accounts.google.com](https://accounts.google.com) a přihlaste se svým účtem Google. Pokud tak činíte poprvé, dokončete nejprve proces vytvoření účtu.
  </Step>
  <Step title="Získejte přihlašovací údaje k API">
    1. Otevřete [Google Cloud Console](https://console.cloud.google.com).
    2. Vytvořte nový projekt (nebo vyberte existující).
    3. Přejděte do **APIs & Services → Library** a aktivujte **Custom Search API**.
    4. Přejděte do **APIs & Services → Credentials** a klikněte na **Create Credentials → API key**.
    5. Zkopírujte svůj nový klíč API a uložte jej na bezpečné místo.
    6. Vytvořte Programmable Search Engine na [programmablesearchengine.google.com](https://programmablesearchengine.google.com) a zkopírujte si **Search Engine ID** (`cx`).
  </Step>
  <Step title="Odešlete svůj první požadavek">
    V níže uvedeném příkazu nahraďte `YOUR_API_KEY` a `YOUR_SEARCH_ENGINE_ID` hodnotami, které jste zkopírovali, a poté jej spusťte v terminálu:

    ```bash
    curl -X GET "https://www.googleapis.com/customsearch/v1?q=hello+world&key=YOUR_API_KEY&cx=YOUR_SEARCH_ENGINE_ID"
    ```
  </Step>
  <Step title="Zkontrolujte odpověď">
    Úspěšný požadavek vrátí objekt JSON obsahující metadata vyhledávání a pole výsledků. Měli byste vidět odpověď podobnou této:

    ```json
    {
      "kind": "customsearch#search",
      "url": {
        "type": "application/json",
        "template": "https://www.googleapis.com/customsearch/v1?q={searchTerms}&..."
      },
      "queries": {
        "request": [
          {
            "title": "Google Custom Search - hello world",
            "totalResults": "4970000000",
            "searchTerms": "hello world",
            "count": 10,
            "startIndex": 1
          }
        ]
      },
      "items": [
        {
          "kind": "customsearch#result",
          "title": "Hello, World! – Wikipedia",
          "htmlTitle": "\u003cb\u003eHello, World!\u003c/b\u003e – Wikipedia",
          "link": "https://en.wikipedia.org/wiki/%22Hello,_World!%22_program",
          "snippet": "A \"Hello, World!\" program is generally a simple computer program that outputs the phrase \"Hello, World!\" to a display device."
        }
      ]
    }
    ```

    Pole `items` obsahuje vaše výsledky vyhledávání. Každý objekt zahrnuje název stránky, URL (`link`) a krátký úryvek (`snippet`), který můžete přímo zobrazit ve svém uživatelském rozhraní.
  </Step>
</Steps>

<Tip>
  Výše uvedený příklad používá pro autentizaci jednoduchý klíč API. Rozhraní Google API také podporují OAuth 2.0 pro požadavky, které přistupují k uživatelským datům. Úplný přehled všech podporovaných metod autentizace najdete v [průvodci autentizací](/api/authentication).
</Tip>
