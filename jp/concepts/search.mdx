Google 検索は毎年、数千億ページを処理し、数兆件のクエリに応答する、世界で最も広く使われている情報検索システムです。ご自身の検索テクニックを磨く場合でも、Google がコンテンツを正しく表面化するようコンテンツを最適化する場合でも、検索機能を直接製品に組み込む場合でも、内部の仕組みを理解しておくことは大きなアドバンテージになります。

## 検索の仕組み

Google 検索は、バックグラウンドで継続的に動く 3 つの大きなステージで動作しています。

**クロール** — Google の自動クローラー（総称して Googlebot）は Web 上のリンクをたどり、新しいページや更新されたページを発見します。`robots.txt` ファイルや `<meta name="robots">` タグを使ってクローラーを誘導し、何を取得するかを制御できます。

**インデックス化** — ページがクロールされると、Google はそのコンテンツ（テキスト、画像、構造化データなど）を解析し、その表現を検索インデックスに保存します。明確な見出し、説明的なメタデータ、有効なスキーママークアップを備えた構造の良いページは、正確にインデックス化されやすくなります。

**ランキング** — ユーザーがクエリを送信すると、Google のランキングシステムは何百ものシグナル（関連性、ページ品質、コンテキスト、鮮度など）を評価して結果を順序付けます。単一の要因で順位が決まることはなく、アルゴリズムはシグナルを総合的に評価し、そのクエリに最も有用な結果を表示します。

<Note>
  Google はすべてのページのインデックス化を保証していません。Google Search Console を使って、カバレッジの監視、クロールエラーの特定、重要な URL の（再）インデックスの依頼を行ってください。
</Note>

## 検索演算子

検索演算子は、Google の検索ボックスに直接入力して結果を絞り込むための特別なコマンドです。リサーチ、競合分析、自サイトの表示状況の監査、インデックス問題のデバッグなどに役立ちます。

| 演算子 | 構文 | 説明 |
|---|---|---|
| `site:` | `site:example.com` | 結果を特定のドメインまたはサブドメイン上のページに制限します。 |
| `filetype:` | `filetype:pdf` | 特定のファイルタイプ（pdf、docx、xlsx など）の結果を返します。 |
| `intitle:` | `intitle:keyword` | HTML の `<title>` タグにキーワードを含むページに一致します。 |
| 完全一致フレーズ | `"machine learning"` | 単語のシーケンスに完全に一致する結果のみを返します。 |
| 除外語 | `-keyword` | 指定した単語やフレーズを含む結果を除外します。 |

演算子は 1 つのクエリ内で組み合わせられます。たとえば、`site:docs.example.com filetype:pdf -intitle:archive` は、ドキュメントサブドメイン上でタイトルに「archive」を含まない PDF ファイルを検索します。

<Tip>
  演算子の前に `OR`（大文字）を付けると、いずれかの条件に一致させることができます — たとえば `site:example.com OR site:example.io` は、両方のドメインからの結果を 1 回のクエリで返します。
</Tip>

## カスタム検索エンジン (CSE)

カスタム検索エンジンを使うと、Web 全体ではなく特定のサイトやページ群にスコープを絞ったブランド検索体験を作成できます。ドキュメント、ヘルプセンター、EC カタログに検索バーを追加するのに便利です。

**カスタム検索エンジンを作成するには:**

1. [Programmable Search Engine のコントロールパネル](https://programmablesearchengine.google.com/controlpanel/all)にアクセスします。
2. **Add** をクリックし、検索対象のサイトまたは URL パターンを入力します。
3. 検索エンジンに名前を付けて保存します — Google は検索エンジンを識別する一意の **Search Engine ID** (`cx` パラメーター) を生成します。
4. **Look and feel** で外観をカスタマイズし、埋め込みスニペットをページにコピーします。

<Note>
  CSE の結果は、通常の Google 検索と同じインデックスルールに従います。ページがインデックス化されていない場合、CSE の結果にも表示されません。
</Note>

## Programmable Search API

Programmable Search JSON API は、カスタム検索エンジンの結果にプログラムからアクセスできる仕組みを提供します。Google の UI を埋め込むことなく、自身のアプリケーション内で検索結果を取得、整形、表示できます。

主な機能は次のとおりです。

- CSE にクエリを送信し、タイトル、URL、スニペット、豊富なメタデータを含む構造化された JSON レスポンスを受け取る。
- `dateRestrict`、`sort`、`filter` パラメーターを適用して、リクエスト時に結果を絞り込む。
- `searchType=image` パラメーターを使って、定義したスコープ内で画像を検索する。

完全なリクエスト/レスポンススキーマ、認証要件、コードサンプルについては、[Search API リファレンス](/api/search)をご覧ください。
