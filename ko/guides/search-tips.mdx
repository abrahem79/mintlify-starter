Google Search의 파워 유저가 된다는 것은 몇 개의 키워드를 입력하고 최선의 결과를 바라는 것 이상을 의미합니다. 올바른 연산자, 필터, 기법을 사용하면 필요한 결과를 정확히 짚어낼 수 있습니다 — 정부 사이트 깊숙이 묻힌 특정 파일 유형이든, 지난주에 게시된 기사든, 반쯤 기억나는 문서의 정확한 구문이든. 아래 팁은 더 스마트하게 검색하고 관련 없는 결과를 스크롤하는 데 드는 시간을 줄여 줍니다.

## 날짜로 다듬기

최신 정보가 필요할 때는 날짜 필터를 사용해 결과를 특정 시간 창으로 제한하세요. 검색을 실행한 후 검색창 아래의 **도구**를 클릭한 다음 **모든 날짜** 드롭다운을 여세요. 프리셋 범위(지난 1시간, 지난 24시간, 지난 주, 지난 달, 지난 해)에서 선택하거나 **맞춤 범위**를 선택해 특정 시작 및 종료 날짜를 입력하세요.

이는 소프트웨어 릴리스, 뉴스 이벤트, 규제 변경 등 빠르게 변화하는 주제에서 특히 유용하며, 오래된 결과가 오도할 수 있는 곳에서 유효합니다.

## 검색 연산자

검색 연산자는 Google이 반환하는 것을 형성하기 위해 검색창에 직접 입력하는 특별한 명령입니다. 더 정확한 결과를 얻기 위해 단일 쿼리에서 여러 연산자를 결합하세요.

| 연산자 | 예시 | 기능 |
|---|---|---|
| `site:` | `site:docs.google.com drive` | 결과를 특정 도메인이나 서브도메인으로 제한 |
| `filetype:` | `filetype:pdf annual report` | 지정된 유형의 파일만 반환(pdf, docx, xlsx 등) |
| `intitle:` | `intitle:privacy policy` | 페이지 제목에 해당 용어가 포함된 페이지 일치 |
| `inurl:` | `inurl:signup google` | URL에 해당 용어가 포함된 페이지 일치 |
| `"exact phrase"` | `"two-factor authentication"` | 인용된 정확한 구문이 포함된 결과 반환 |
| `OR` | `Google Docs OR Google Sheets tutorial` | 두 용어 중 하나에 일치하는 결과 반환(반드시 대문자) |
| `-` (마이너스) | `python tutorial -youtube` | 마이너스 기호 뒤의 용어가 포함된 결과 제외 |
| `*` (와일드카드) | `"the * of Google"` | 인용된 구문 내에서 어떤 단어든 대체하는 자리 표시자로 작동 |

## Verbatim 검색

기본적으로 Google은 쿼리를 느슨하게 해석합니다 — 동의어를 바꾸거나, 철자를 교정하거나, 중요하지 않다고 판단되는 단어를 생략할 수 있습니다. 입력한 모든 단어에 대해 정확한 일치를 강제하려면 **Verbatim** 모드를 사용하세요:

1. 평소처럼 검색을 실행하세요.
2. 검색창 아래의 **도구**를 클릭하세요.
3. **모든 결과** 드롭다운을 여세요.
4. **Verbatim**을 선택하세요.

이제 Google은 입력한 형태 그대로 입력한 단어를 정확히 포함하는 페이지만 반환합니다. 오류 메시지, 코드 스니펫, 흔치 않은 고유명사를 검색할 때 매우 유용합니다.

## 이미지 검색 팁

Google Images는 기본 키워드 검색을 넘어 시각 자료를 찾기 위한 여러 강력한 방법을 제공합니다.

**이미지로 검색:** [images.google.com](https://images.google.com)으로 이동해 검색창의 카메라 아이콘을 클릭한 다음, 이미지 URL을 붙여넣거나 기기에서 파일을 업로드하세요. Google은 시각적으로 유사한 이미지를 찾고 사진에 무엇이 있는지 식별합니다.

**크기, 색상, 유형별로 필터링:** 이미지 검색을 실행한 후 **도구**를 클릭해 필터 드롭다운을 표시하세요:

- **크기** — 큼, 중간, 아이콘 중에서 선택하거나 정확한 크기를 입력하세요.
- **색상** — 우세한 색상별로 필터링하거나 흑백 또는 투명을 선택하세요.
- **유형** — 클립 아트, 선 그림, GIF, 사진으로 좁히세요.
- **사용 권한** — 재사용할 수 있는 이미지가 필요하다면 Creative Commons 라이선스로 필터링하세요.

## 음성 검색

모바일과 데스크톱 Chrome에서 Google 검색창의 마이크 아이콘을 클릭하고 쿼리를 말하세요. Google이 여러분의 말을 필사하고 자동으로 검색을 실행합니다. 음성 검색은 "Google 스토어는 몇 시에 닫나요?" 또는 "Gmail에서 서명은 어떻게 추가하나요?"처럼 자연어 질문에 특히 잘 작동합니다.

<Tip>
단일 웹사이트로 범위가 지정된 검색이 필요하다면 — 예를 들어 여러분의 자체 문서나 내부 지식 기반 — [Custom Search Engine](/concepts/search)을 만드세요. 지정한 도메인만 쿼리하며 선택적 순위 조정과 브랜딩된 인터페이스를 갖춘, Google 기반 검색창을 임베드할 수 있습니다.
</Tip>
