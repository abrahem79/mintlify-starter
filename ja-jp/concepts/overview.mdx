Google のプラットフォームは、情報を見つけ、作成し、共有するライフサイクル全体をカバーする幅広いクラウドベースのサービスをひとつにまとめています。ウェブで答えを探す、共有ドキュメントでチームメイトと協業する、Google のインフラを活用したアプリケーションを構築する ── どのサービスもシームレスに連携するよう設計されており、個人、チーム、開発者が上に構築できる一貫した基盤を提供します。

## Google プラットフォームの 3 つの柱

Google はコアオファリングを、それぞれ異なるが補完的な目的を果たす 3 つの相互接続された領域に整理しています。

### 1. Search

Google Search は、毎日何十億もの検索を処理する入り口です。ウェブ検索だけでなく、Google の検索技術は社内ツール、自社製品に埋め込むカスタム検索エンジン、プログラマティックに情報を取得・ランク付けする API も支えています。Search の仕組みを理解することで、ユーザーにとって、そして自分自身にとって、適切なコンテンツを適切なタイミングで表示できるようになります。

### 2. Google Workspace

Google Workspace は、Google のクラウドベース生産性・コラボレーションアプリケーション群です。Gmail、Google Drive、Docs、Sheets、Slides、Meet が含まれ、いずれもリアルタイムコラボレーションを軸に構築されており、あらゆるデバイスからアクセスできます。Workspace はチーム全員が単一の共有環境で作業するよう設計されており、コンテンツの閲覧、コメント、編集を誰ができるかを細かく制御できます。

### 3. 開発者向け API

Google は、検索結果をアプリケーションに埋め込む、Workspace ドキュメントを読み書きする、認証・地図・機械学習モデルを統合する ── といったサービスへのプログラマティックなアクセスを提供する豊富な API 群を公開しています。API は標準的な REST および gRPC の規約に従い、認可には OAuth 2.0 を使用し、本ドキュメントの API リファレンスセクションに詳細が記載されています。
