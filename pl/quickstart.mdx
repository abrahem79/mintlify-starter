title: "Szybki start"
description: "Zacznij od przewodnika po najszybszej drodze do sukcesu"
---

Opisz, jak ktoś zaczyna korzystać z Twojego produktu. Co jest pierwszą rzeczą, którą musi zrobić? Czy są jakieś wymagania wstępne?

Szybki start powinien przeprowadzić kogoś od zera do korzystania z Twojego produktu. Użytkownik odniesie szybki sukces i zrozumie, co może osiągnąć.

## Wymagania wstępne

Zanim zaczniesz, musisz mieć:

- Wymaganie pierwsze (na przykład Node.js 18+, bezpłatne konto, klucz API)
- Wymaganie drugie (na przykład kompatybilne urządzenie, kompatybilną przeglądarkę, kompatybilny system operacyjny)

## Rozpocznij

<Steps>
  <Step title="Instalacja">
    Opisz, jak zainstalować swój produkt lub się zarejestrować.

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="Konfiguracja">
    Opisz konfigurację lub ustawienia potrzebne przed pierwszym użyciem.

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="Uruchom">
    Pokaż pierwszą czynność, którą użytkownik wykonuje, aby zobaczyć, jak to działa.

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  Zapewnij użytkownikom możliwość uzyskania pomocy. Może to być link do strony wsparcia, czat z agentem obsługi klienta lub forum dla Twojego produktu.

  Przykład: Potrzebujesz pomocy? Skontaktuj się z nami pod adresem [support@yourcompany.com](mailto:support@yourcompany.com).
</Tip>
