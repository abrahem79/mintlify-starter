Que vous soyez un développeur qui intègre les API de Google à son produit ou un nouvel utilisateur qui configure son premier compte, cette documentation vous guidera à chaque étape.

## Fonctionnement

Débuter avec Google ne prend que quelques minutes. Suivez ces trois étapes pour passer de zéro à une intégration complète.

<Steps>
  <Step title="Créer un compte Google">
    Rendez-vous à [accounts.google.com](https://accounts.google.com) et inscrivez-vous pour obtenir un compte Google gratuit. Votre compte est votre passeport vers tous les services Google — Search, Gmail, Drive, Cloud et plus encore.
  </Step>
  <Step title="Activer les services dont vous avez besoin">
    Rendez-vous à la [console Google Cloud](https://console.cloud.google.com) pour créer un projet et activer les API et services précis dont votre cas d'utilisation a besoin, comme l'API Custom Search, l'API Maps ou l'API Gmail.
  </Step>
  <Step title="Connecter vos applications par l'API">
    Générez des identifiants d'API dans la console Cloud et utilisez les API REST ou les bibliothèques clientes de Google pour intégrer les services Google directement à votre application. Consultez le [démarrage rapide](/quickstart) pour effectuer votre premier appel d'API en quelques minutes.
  </Step>
</Steps>
