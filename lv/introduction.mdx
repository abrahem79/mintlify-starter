## Kā tas darbojas

Darba sākšana ar Google aizņem tikai dažas minūtes. Izpildiet šos trīs soļus, lai no nulles nokļūtu līdz pilnīgai integrācijai.

<Steps>
  <Step title="Izveidojiet Google kontu">
    Apmeklējiet [accounts.google.com](https://accounts.google.com) un reģistrējieties bezmaksas Google kontam. Jūsu konts ir pase uz katru Google pakalpojumu — meklēšanu, Gmail, Drive, Cloud un citiem.
  </Step>
  <Step title="Iespējojiet nepieciešamos pakalpojumus">
    Dodieties uz [Google Cloud konsoli](https://console.cloud.google.com), lai izveidotu projektu un iespējotu konkrētas API un pakalpojumus, kas nepieciešami jūsu lietošanas gadījumam, piemēram, Custom Search API, Maps API vai Gmail API.
  </Step>
  <Step title="Savienojiet savas lietotnes, izmantojot API">
    Ģenerējiet API akreditācijas datus Cloud konsolē un izmantojiet Google REST vai klienta bibliotēku API, lai tieši integrētu Google pakalpojumus savā lietojumprogrammā. Skatiet [Ātro sākumu](/quickstart), lai dažu minūšu laikā veiktu savu pirmo API izsaukumu.
  </Step>
</Steps>
