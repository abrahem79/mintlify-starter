---
title: "البدء السريع"
description: "ابدأ بدليل يرشدك إلى أسرع طريق للوصول إلى نتيجة ناجحة"
---

اشرح كيف يبدأ الشخص باستخدام منتجك. ما أول شيء عليه فعله؟ وهل هناك أي متطلبات مسبقة؟

يجب أن ينقل دليل البدء السريع الشخص من الصفر إلى استخدام منتجك. سيحصل على إنجاز سريع وفكرة عمّا يمكنه تحقيقه.

## المتطلبات المسبقة

قبل أن تبدأ، يجب أن يتوفر لديك:

- المتطلب الأول (على سبيل المثال، Node.js 18+، حساب مجاني، مفتاح API)
- المتطلب الثاني (على سبيل المثال، جهاز متوافق، متصفح متوافق، نظام تشغيل متوافق)

## البدء

<Steps>
  <Step title="التثبيت">
    اشرح كيفية تثبيت منتجك أو التسجيل فيه.

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="الإعداد">
    اشرح أي تهيئة أو إعداد مطلوب قبل الاستخدام الأول.

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="التشغيل">
    اعرض أول شيء يقوم به المستخدم ليرى المنتج يعمل.

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  وفِّر للأشخاص طريقةً للحصول على المساعدة. يمكن أن يكون ذلك رابطًا إلى صفحة الدعم، أو محادثة مع وكيل خدمة العملاء، أو منتدى خاص بمنتجك.

  مثال: هل تحتاج إلى مساعدة؟ تواصل معنا عبر [support@yourcompany.com](mailto:support@yourcompany.com).
</Tip>
