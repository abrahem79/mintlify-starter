---

سواء كنت مستخدمًا جديدًا لـ Google أو مطورًا متمرسًا يعمل مع واجهات Google البرمجية، فمن المحتمل أن تصادف أسئلة حول كيفية عمل الحسابات والتخزين والفوترة وضوابط الوصول. تجمع هذه الصفحة إجابات على الأسئلة الأكثر شيوعًا عبر منتجات Google الاستهلاكية وتطبيقات Workspace ومنصة المطورين — حتى تتمكن من الحصول على إجابات سريعة دون الحفر عبر مراكز مساعدة متعددة.

<AccordionGroup>
  <Accordion title="كيف أعيد تعيين كلمة مرور Google الخاصة بي؟">
    يمكنك إعادة تعيين كلمة مرور Google الخاصة بك من صفحة استرداد الحساب على [accounts.google.com/signin/recovery](https://accounts.google.com/signin/recovery). أدخل عنوان البريد الإلكتروني المرتبط بحسابك واتبع المطالبات — سيرسل Google رمز تحقق إلى بريدك الإلكتروني للاسترداد أو رقم هاتفك. بمجرد التحقق، ستتمكن من إنشاء كلمة مرور جديدة. إذا فقدت الوصول إلى جميع خيارات الاسترداد، يوفر Google عملية التحقق من الهوية حيث سيُطرح عليك أسئلة لتأكيد هويتك بناءً على سجل حسابك.
  </Accordion>

  <Accordion title="لماذا لا يعمل مفتاح API الخاص بي؟">
    الأسباب الأكثر شيوعًا لتوقف مفتاح API عن العمل هي أن المفتاح قد قُيّد بعناوين IP أو مراجع محددة لا تتطابق مع بيئتك الحالية، أو أن المفتاح لا يحتوي على واجهة API الضرورية مُفعّلة في مشروع Google Cloud الخاص بك، أو أن المفتاح قد تم حذفه أو إعادة إنشائه. افتح [Google Cloud Console](https://console.cloud.google.com)، وانتقل إلى **APIs & Services → Credentials**، وتحقق من قيود مفتاحك وحالته. أيضًا تأكد من تفعيل API المستهدف (مثل Maps JavaScript API أو Sheets API) ضمن **APIs & Services → Enabled APIs & services**.
  </Accordion>

  <Accordion title="ما الذي يُحسب ضمن حصة تخزين Google الخاصة بي؟">
    تتم مشاركة 15 جيجابايت من تخزين Google المجاني عبر Gmail (رسائل البريد الإلكتروني والمرفقات)، وGoogle Drive (الملفات المحمّلة)، وGoogle Photos (الصور والفيديوهات المنسوخة احتياطيًا). Google Docs وSheets وSlides وForms وDrawings التي يتم إنشاؤها أصلاً بتنسيقات Google **لا** تُحسب ضمن حصتك. ومع ذلك، فإن الملفات المحمّلة إلى Drive بتنسيقات أخرى — مثل `.docx` أو `.xlsx` أو `.pdf` — تستهلك التخزين. يمكنك التحقق من استخدامك الحالي والتفصيل على [one.google.com/storage](https://one.google.com/storage).
  </Accordion>

  <Accordion title="كيف أحذف حساب Google الخاص بي؟">
    يمكنك حذف حساب Google الخاص بك بشكل دائم من قسم **Data & privacy** في إعدادات حسابك. انتقل إلى [myaccount.google.com](https://myaccount.google.com)، وانقر على **Data & privacy**، وقم بالتمرير إلى **More options**، وانقر على **Delete your Google Account**. سيطلب منك Google تنزيل نسخة من بياناتك أولاً باستخدام Google Takeout. لاحظ أن الحذف دائم — سيتم فقد Gmail وملفات Drive وجميع البيانات المرتبطة ولا يمكن استعادتها بعد انتهاء فترة السماح.
  </Accordion>

  <Accordion title="هل يمكنني استخدام واجهات Google البرمجية مجانًا؟">
    تقدم العديد من واجهات Google البرمجية طبقة مجانية مع حدود استخدام سخية — على سبيل المثال، تتضمن Maps JavaScript API 200 دولار شهريًا من الاعتمادات المجانية، واستدعاءات Google Sheets API مجانية حتى حدود الاستخدام المعينة لكل مشروع. ومع ذلك، يتطلب الاستخدام عالي الحجم، وبعض واجهات API المميزة (مثل Google Maps Routes Preferred)، وميزات فئة المؤسسات إعداد حساب فوترة في Google Cloud. يمكنك مراجعة الأسعار لأي واجهة API محددة على [cloud.google.com/pricing](https://cloud.google.com/pricing) أو ضمن صفحة توثيق API الفردية.
  </Accordion>

  <Accordion title="كيف أنقل ملكية Google Doc؟">
    لنقل ملكية Google Doc أو Sheet أو Slide، افتح الملف وانقر على **Share** في الزاوية العلوية اليمنى. ابحث عن الشخص الذي تريد نقل الملكية إليه (يجب أن يكون لديه حق الوصول بالفعل)، وانقر على القائمة المنسدلة بجوار اسمه، وحدد **Transfer ownership**. سيتلقى المستلم إشعارًا بالبريد الإلكتروني ويجب عليه قبول النقل. لاحظ أنه يمكنك فقط نقل الملكية إلى مستخدم آخر داخل نفس مؤسسة Google Workspace، أو للحسابات الشخصية، إلى صاحب حساب Google آخر.
  </Accordion>

  <Accordion title="كيف أبلغ عن بريد إلكتروني للبريد المزعج أو التصيد الاحتيالي في Gmail؟">
    للإبلاغ عن بريد إلكتروني مزعج في Gmail، افتح الرسالة، وانقر على **قائمة النقاط الثلاث** (⋮) في الجزء العلوي الأيمن من البريد الإلكتروني، وحدد **Report spam** أو **Report phishing**. يرسل الإبلاغ عن التصيد الاحتيالي البريد الإلكتروني إلى Google للمراجعة ويساعد على حماية المستخدمين الآخرين من هجمات مماثلة. سيقوم Gmail أيضًا تلقائيًا بنقل البريد الإلكتروني خارج صندوق الوارد الخاص بك. إذا تلقيت رسائل بريد إلكتروني للتصيد الاحتيالي تنتحل شخصية شركة أو مؤسسة، يمكنك الإبلاغ عنها بالإضافة إلى [فريق Google Safe Browsing](https://safebrowsing.google.com/safebrowsing/report_phish/).
  </Accordion>

  <Accordion title="ما هي حدود المعدل لواجهة Google Search API؟">
    تسمح Google Custom Search JSON API بما يصل إلى **100 استعلام بحث يوميًا** مجانًا، مع توفر استعلامات إضافية بسعر 5 دولارات لكل 1000 استعلام (حتى 10000 يوميًا). ينطبق هذا على واجهة Programmable Search Engine API — إذا كنت تستخدم Google Search Console API أو واجهات API الأخرى المتعلقة بالبحث، فتختلف الحدود ويتم توثيقها بشكل منفصل. يمكنك مراقبة استخدامك وتكوين حصص الطلبات في [Google Cloud Console](https://console.cloud.google.com) ضمن **APIs & Services → Quotas**. لاحتياجات البحث ذات الحجم الكبير جدًا، يقدم Google خيارات على مستوى المؤسسات من خلال Google Cloud.
  </Accordion>
</AccordionGroup>
