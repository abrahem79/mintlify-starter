## كيف يعمل

يستغرق البدء مع Google بضع دقائق فقط. اتبع هذه الخطوات الثلاث للانتقال من الصفر إلى التكامل الكامل.

<Steps>
  <Step title="إنشاء حساب Google">
    قم بزيارة [accounts.google.com](https://accounts.google.com) وسجل للحصول على حساب Google مجاني. حسابك هو جواز سفرك إلى كل خدمات Google — البحث وGmail وDrive وCloud والمزيد.
  </Step>
  <Step title="تفعيل الخدمات التي تحتاجها">
    توجه إلى [Google Cloud Console](https://console.cloud.google.com) لإنشاء مشروع وتفعيل واجهات API والخدمات المحددة التي تتطلبها حالة استخدامك، مثل Custom Search API أو Maps API أو Gmail API.
  </Step>
  <Step title="اربط تطبيقاتك عبر الواجهة البرمجية">
    أنشئ بيانات اعتماد API في Cloud Console واستخدم واجهات Google REST أو مكتبات العميل لدمج خدمات Google مباشرة في تطبيقك. اطلع على [البدء السريع](/quickstart) لإجراء أول استدعاء لواجهة API خلال دقائق.
  </Step>
</Steps>
