このクイックスタートでは、Google へのサインイン、API 認証情報の取得、そして最初の API リクエストの実行までを 10 分以内でご案内します。最後には、ライブの検索結果を返す動作する API 呼び出しが手に入り、そのままご自身のアプリケーションで発展させることができます。

## 前提条件

始める前に、以下がそろっていることを確認してください。

- **Google アカウント** — まだお持ちでない場合は、[無料で作成](https://accounts.google.com/signup)できます。
- **HTTP の基本知識** — GET/POST リクエストの送信や JSON レスポンスの読み取りに慣れていること。
- コマンドラインターミナル、または [curl](https://curl.se/) や [Postman](https://www.postman.com/) などの HTTP クライアント。

## 手順

<Steps>
  <Step title="サインインする">
    [accounts.google.com](https://accounts.google.com) にアクセスし、Google アカウントでサインインします。初めての場合は、先に進む前にアカウント作成フローを完了してください。
  </Step>
  <Step title="API 認証情報を取得する">
    1. [Google Cloud Console](https://console.cloud.google.com) を開きます。
    2. 新しいプロジェクトを作成する（または既存のものを選択する）。
    3. **APIs & Services → Library** に移動し、**Custom Search API** を有効化します。
    4. **APIs & Services → Credentials** に移動し、**Create Credentials → API key** をクリックします。
    5. 新しい API キーをコピーし、安全な場所に保管します。
    6. [programmablesearchengine.google.com](https://programmablesearchengine.google.com) で Programmable Search Engine を作成し、**Search Engine ID** (`cx`) をコピーします。
  </Step>
  <Step title="最初のリクエストを実行する">
    以下のコマンド内の `YOUR_API_KEY` と `YOUR_SEARCH_ENGINE_ID` をコピーした値に置き換え、ターミナルで実行してください。

    ```bash
    curl -X GET "https://www.googleapis.com/customsearch/v1?q=hello+world&key=YOUR_API_KEY&cx=YOUR_SEARCH_ENGINE_ID"
    ```
  </Step>
  <Step title="レスポンスを確認する">
    リクエストが成功すると、検索メタデータと結果の配列を含む JSON オブジェクトが返されます。以下のようなレスポンスが表示されるはずです。

    ```json
    {
      "kind": "customsearch#search",
      "url": {
        "type": "application/json",
        "template": "https://www.googleapis.com/customsearch/v1?q={searchTerms}&..."
      },
      "queries": {
        "request": [
          {
            "title": "Google Custom Search - hello world",
            "totalResults": "4970000000",
            "searchTerms": "hello world",
            "count": 10,
            "startIndex": 1
          }
        ]
      },
      "items": [
        {
          "kind": "customsearch#result",
          "title": "Hello, World! – Wikipedia",
          "htmlTitle": "\u003cb\u003eHello, World!\u003c/b\u003e – Wikipedia",
          "link": "https://en.wikipedia.org/wiki/%22Hello,_World!%22_program",
          "snippet": "A \"Hello, World!\" program is generally a simple computer program that outputs the phrase \"Hello, World!\" to a display device."
        }
      ]
    }
    ```

    `items` 配列には検索結果が含まれます。各オブジェクトにはページタイトル、URL (`link`)、UI にそのまま表示できる短い `snippet` が含まれます。
  </Step>
</Steps>

<Tip>
  上記の例では、シンプルな API キーを認証に使用しています。Google API は、ユーザーデータにアクセスするリクエスト向けに OAuth 2.0 もサポートしています。サポートされているすべての認証方式の詳細については、[認証ガイド](/api/authentication)をご覧ください。
</Tip>
