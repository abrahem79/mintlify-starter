Popište, jak někdo začíná používat váš produkt. Co je první věc, kterou musí udělat? Jsou nějaké předpoklady?

Rychlý start by měl uživatele provést od nuly až po používání vašeho produktu. Získají rychlý úspěch a představu o tom, čeho mohou dosáhnout.

## Předpoklady

Než začnete, musíte mít:

- Požadavek jedna (například Node.js 18+, bezplatný účet, API klíč)
- Požadavek dva (například kompatibilní zařízení, kompatibilní prohlížeč, kompatibilní operační systém)

## Začínáme

<Steps>
  <Step title="Instalace">
    Popište, jak nainstalovat váš produkt nebo se zaregistrovat.

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="Konfigurace">
    Popište případné nastavení nebo konfiguraci potřebnou před prvním použitím.

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="Spusťte to">
    Ukažte první věc, kterou uživatel udělá, aby viděl, že to funguje.

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  Poskytněte lidem způsob, jak získat pomoc. Může to být odkaz na stránku podpory, chat s pracovníkem zákaznické podpory nebo fórum pro váš produkt.

  Příklad: Potřebujete pomoc? Kontaktujte nás na [support@yourcompany.com](mailto:support@yourcompany.com).
</Tip>
